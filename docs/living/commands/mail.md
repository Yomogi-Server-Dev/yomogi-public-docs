# メール

オフラインのプレイヤーへも送れる、フォーム形式のメール機能です。過去に一度でもサーバーに参加したことがあるプレイヤーであれば、オフライン中でも送れます。

## 使い方

/mailでメールメニューを開きます。個別のコマンドから直接操作することもできます。

| command | 説明 | 権限 |
|---|---|---|
| /mail | メールメニュー画面を開く | 全員 |
| /seemail | 受信ボックスを見る | 全員 |
| /writemail | メールを送る | 全員 |
| /htmail | 送信履歴を見る | 全員 |

## お金を添付する

メールにはYGを添付できます。添付されたお金は、受信者がそのメールを**初めて開いた時点**で付与されます。

## 制限

- 本文は最大500文字です
- `<n` と入力すると改行になります
- お互いにミュートしているプレイヤーとの間ではメールを送受信できません
