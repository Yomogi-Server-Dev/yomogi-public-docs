# メール

オフラインのプレイヤーへも送れる、フォーム形式のメール機能です。過去に一度でもサーバーに参加したことがあるプレイヤーであれば、オフライン中でも送れます。

## 使い方

`/mail`でメールメニューを開きます。個別のコマンドから直接操作することもできます。

| command | 説明 | 権限 |
|---|---|---|
| `/mail` | メールメニュー画面を開く | 全員 |
| `/seemail` | 受信ボックスを見る | 全員 |
| `/writemail` | メールを送る | 全員 |
| `/htmail` | 送信履歴を見る | 全員 |

受信ボックスの画面からは、読んだメールの削除もできます。

## お金を添付する

メールにはYGを添付できます。添付されたお金は、受信者がそのメールを**初めて開いた時点**で付与されます。未開封のまま放置していても、開いた瞬間にきちんと反映されます。

## 制限

- 本文は最大500文字です
- 本文中に`<n`と入力すると、そこで改行されます
- お互いにミュートしているプレイヤーとの間ではメールを送受信できません
- 送信先は、**過去に一度でもこのサーバーに参加したことがあるプレイヤー**である必要があります(オフラインでも送信可能です)
