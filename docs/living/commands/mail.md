# メール

オフラインのプレイヤーへも送れる、フォーム形式のメール機能です。過去に一度でもサーバーに参加したことがあるプレイヤーであれば、オフライン中でも送れます。

## 使い方

`/mail`でメールメニューを開きます。個別のコマンドから直接操作することもできます。

| コマンド | 説明 | 権限 |
|---|---|---|
| `/mail` | メールメニュー画面を開く | 全員 |
| `/seemail` | 受信ボックスを見る | 全員 |
| `/writemail` | メールを送る | 全員 |
| `/htmail` | 送信履歴を見る | 全員 |

受信ボックスの画面からは、読んだメールの削除もできます。

## お金を添付する

メールにはYGを添付できます。添付されたお金は、受け取った人がそのメールを**初めて開いたとき**に渡されます。しばらく開かずに放置していても、開いた瞬間にきちんと受け取れます。

## 制限

- 本文は最大500文字です
- 本文中に`<n`と入力すると、そこで改行されます
- [ミュート](https://docs.ymg24.org/docs/living/commands/mute)しているプレイヤーとの間ではメールを送受信できません
- 送り先は、**過去に一度でもこのサーバーに参加したことがあるプレイヤー**である必要があります(オフラインでも送れます)
