# 料理

野菜・果物・調味料などの食材から、餃子・ラーメンなどの**完成した料理43種**と**お酒6種**を作れる機能です。飲食店を経営して、食材や完成した料理・お酒を売ることができます。

## 食材の集め方

| 入手方法 | 対象 |
|---|---|
| [公式ショップ](/docs/living/commands/shop)で購入 | 野菜・果物・調味料(塩・酢・醤油・味噌) |
| クラフト台で作る | 挽き肉・生地・麺・乳製品(クリーム・チーズ・バター・ヨーグルト)・食用油など |
| 包丁で変換する | 魚介類(釣った魚をまとめて変換) |

:::tip 包丁で魚を魚介類に変える
包丁を持って右クリックすると、持ち物の魚が**3匹ごとに魚介類1個**に変換されます。何匹使って何個できるかを確認する画面が出てから実行されます。
:::

## 料理本

作り方が分からなくなったら**料理本**を右クリックしてください。ジャンル別のレシピ一覧が開き、材料・作る場所・できあがる数・食べたときの効果が確認できます。

:::info 料理本・包丁の入手方法
料理本・包丁はショップやガチャでは手に入らず、運営からの配布やイベントで受け取れます。
:::

## 完成した料理を作る

料理によって作る場所が違います。

| 作る場所 | 品数 | 何を作るか |
|---|---|---|
| クラフト台 | 18品 | 麺類・スープ・冷たいもの・漬けものなど |
| コンロ | 17品 | 炒め物・焼き物 |
| 蒸籠 | 4品 | 蒸し物 |
| 揚げ鍋 | 4品 | 揚げ物 |

コンロ・蒸籠・揚げ鍋は、設置してタップすると画面が開き、**作りたい料理と「何回分作るか」(1・4・8・16回分**)を選べます。仕込んだあとしばらく待つと(コンロ10秒・蒸籠20秒・揚げ鍋15秒。まとめて作っても待ち時間は変わりません)できあがるので、もう一度タップすると受け取れます。

:::caution 仕込み中に壊すと材料が戻ります
仕込み中の器具を壊すと、入れた材料がそのまま返ってきます(できあがった料理・お酒は受け取れなくなります)。
:::

## 麺とお酒を作る

- **麺** — 製麺機に生地を持ってタップすると、約5秒で麺2個ができます
- **ビール** — 醸造樽に小麦3個を持ってタップすると仕込みが始まり、約3分後にもう一度タップすると受け取れます
- **日本酒・果実酒** — 醸造樽からできるボトル・徳利はそのままでは飲めません。**ガラスびん3個と一緒にクラフトする**とグラス・おちょこ3杯になり、これで飲めます

お酒(ビール・日本酒・果実酒グラス・カクテル3種)は、どれを飲んでも数秒間だけ**吐き気**が付きます。そのかわり、種類ごとにおまけの効果(移動速度・体力回復・火に強くなる・ジャンプ力アップのいずれか)が短時間だけ付きます。

## 料理を食べると効果が付く

食べる料理の系統によって、短時間の効果が付きます(**アスレチックワールドでは付きません**)。

| 系統 | 効果 |
|---|---|
| 魚介系 | 移動速度 II(3分) |
| 肉系 | ジャンプ力 II(3分) |
| 冷たいもの(かき氷など) | 火に強くなる(5分) |
| 野菜・卵系 | 体力回復(30秒) |

## 飾りに変える

かざり変換台に焼き鳥・ビール・果実酒(瓶)をかざすと、地面に置ける**飾り**に変わります。りょうり変換台にその飾りをかざすと、元の食べ物・飲み物に戻せます。

## 料理図鑑・お酒図鑑

作った料理・お酒は自動的に図鑑へ記録されます。集めた種類が**50%・100%に達すると称号がもらえます**([よもぎ端末](/docs/living/commands/custom-items)の「遊び・実績」カテゴリ、または`/cooking_zukan`から開けます)。

| 図鑑 | 中身 | 50%の称号 | 100%の称号 |
|---|---|---|---|
| 料理図鑑 | 料理43品 | プロの料理人 | 料理の鉄人 |
| お酒図鑑 | 飲めるお酒20種 | 酒好き | バーテンダー |

もらった称号は[称号メニュー](/docs/living/commands/rank)から付け替えられます。

:::tip 「作った」で記録されます
食べた・飲んだ回数ではなく、**作った時点**で図鑑に記録されます。作った物を売っても図鑑の記録は減りません。
:::

料理関連の[ミッション](/docs/living/commands/mission)もあわせてご覧ください。累計で作った個数を数えるミッションや、この図鑑の達成率を目標にしたミッション、餃子・ラーメン・焼き鳥などを納品するミッションがあります。
