# よもぎ端末とオリジナルアイテム

よもぎサーバーには、バニラ(ふつうのマインクラフト)には無いオリジナルのアイテムやブロックがたくさんあります。ここでは代表的なものを紹介します。

:::info 見た目が正しく出ないときは
オリジナルのアイテム・ブロックの見た目は、サーバーのリソースパック(見た目を差し替えるデータ)で表示されています。参加するときにリソースパックを適用していないと、正しい見た目になりません。
:::

## よもぎ端末

サーバーのいろいろな機能を、コマンドを打たずに開けるメニューアイテムです。`/phone`でいつでも受け取れます。

**端末を手に持ってタップ(PCでは右クリック)する**とメニューが開き、カテゴリを選ぶとその中の機能一覧が表示されます。[ミッション](/docs/living/commands/mission)・[ミュート](/docs/living/commands/mute)・[役職変更](/docs/living/commands/role)・[求人掲示板](/docs/living/commands/jobboard)など、多くの機能をここから呼び出せます。

:::tip メニューの形を変えられます
`/setting`の「よもぎ端末をインベントリ形式のUIで開く」をオンにすると、ボタンの一覧ではなく**チェストのような画面**でメニューが開きます。全部の機能が1画面に並び、どれでも1タップで実行できます。
:::

## 便利な道具

| アイテム | 使い方 |
|---|---|
| 携帯クラフト台 | タップすると、作業台を置かなくてもクラフト画面が開きます |
| 圧縮の杖 | タップするとメニューが開き、素材(鉄インゴットや小麦など)とブロック(鉄ブロックや俵など)をまとめて行き来させられます |
| 万能元素 | 傷んだ道具に重ねると、耐久値が全回復します(1つの道具につき使える回数に上限があります) |
| 自動売却機 | 持っているだけで、設定したアイテムを自動で売ってくれます(→[公式ショップ](/docs/living/commands/shop)) |

圧縮の杖は、**名前や説明文が付いていないふつうのアイテムだけ**を変換の対象にします。ガチャの景品などを間違えて変換してしまうことはありません。

## 飾り・その他のアイテム

- **サイリウム**(赤・青・紫・オレンジ・ピンク・緑の6色) — 手に持つと光るスティック。イベントなどで使えます
- **帽子**(70種類) — 頭の防具スロットに入れると帽子として表示されます。攻撃を受けても壊れません
- **シトリン / ミスリル** — ロビーでの交換やデイリーミッションの報酬でもらえる特別なアイテム
- **魚・中華料理・和食など** — 釣りやガチャ、ショップで手に入る食べ物

:::caution 名前が付いたアイテムはクラフトに使えません
ガチャの景品・ミスリル・シトリンなどの特別なアイテムは、素材として消費されてしまわないよう、**クラフトの材料に使えないようになっています**。
:::

## 動かせるブロック

| ブロック | できること |
|---|---|
| ゴミ箱 | タップすると画面が開きます。いらないアイテムを入れて閉じ、確認画面で「捨てる」を選ぶと完全に消えます(キャンセルすれば全部返ってきます) |
| ジュークボックス | サーバーオリジナルのレコードを入れると曲が流れます。素手でタップすると、取り出して停止します |

## 米づくり

稲を育てて、順番に加工していくとご飯が作れます。加工機にアイテムを1つ入れてしばらく待つと完成するので、もう一度タップすると受け取れます。

```
稲 → (収穫) → 籾 → 脱穀機 → 玄米 → 精米機 → 白米 → 洗い場 → 研いだ米 → 炊飯器 → ご飯
```

- 稲はスイレンの葉と同じく、**真下が水源のとき**だけ置けます。下の水が無くなると壊れます
- 骨粉で成長を早められます。育ちきってから壊すと籾と種、育つ前だと種だけが落ちます
- 加工機は**誰が入れたかを覚えていません**。動いている加工機は他の人でも受け取れてしまうので、自分の土地の中に置くことをおすすめします

## クラフトできるオリジナルブロック

| 作れるもの | 材料 |
|---|---|
| ラピス/青氷/スライムのレンガ | 各素材4個を2×2 |
| 組子細工のドア ×4 | 板ガラス3(中央の列)+ 鉄格子3(右の列) |
| 組子細工の窓 ×2 | 板ガラス2(左の列)+ 鉄格子2(右の列) |
| 畳 ×3 | 干し草の俵9個を3×3(作業台が必要) |
| 圧縮木材 ×1 | オークの原木9個(作業台が必要。逆に圧縮木材1個から原木9個に戻せます) |
| 提灯 | ダークオークのハーフ6 + 好きな色の羊毛2 + 松明1 |
| 和室の机 | ガラス3 + マングローブの板材4 |
| おにぎり | ご飯4個を三角形に並べる |

障子・かき氷機・BBQコンロ・パイプなど、上の表に無い装飾ブロックは**クラフトのレシピがなく、運営からの配布やイベントで手に入ります**。

:::caution オリジナルブロックのとなりにカーペットは置けません
マインクラフト側の不具合で、オリジナルのブロックとカーペットが隣り合うと画面が透けて見えてしまいます。これを防ぐため、**オリジナルブロックのとなりにはカーペットを置けない**ようになっています。置こうとするとカーペットは手元に戻り、隣にあったオリジナルブロックはアイテムになって落ちます。
:::

## ボスモブ

イベントなどで、運営がオリジナルのボス「冥獄龍 ヴァルゼノク」を呼び出すことがあります。体力が高く、離れているプレイヤーに向かって突進してきますが、**突進の前に紫のパーティクルで進む道が表示される**ので、よく見ていれば避けられます。

## そのほかのコマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/phone` | よもぎ端末を受け取る | 全員 |
| `/normalize` | 手に持っているアイテムの名前・説明文を消す | 全員 |

:::danger `/normalize`は取り消せません
`/normalize`を使うと、アイテムに付いている名前と説明文が消えます。**元には戻せません。** 大切なアイテムには使わないでください。
:::
