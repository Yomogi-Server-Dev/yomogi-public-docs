# オークション

土地保護が外れた土地(1か月以上のログインが無かった放置土地など)は、運営によってオークションにかけられることがあります。誰でも入札に参加できます。

## 使い方

/auctionでオークション一覧・入札メニューを開きます。開催中のオークションを選ぶと、現在の最高額を確認して入札できます。

## 入札のルール

- 1回の入札で、現在の最高額から最低5,000YGは上乗せする必要があります
- 入札の受付期間は、既定で出品から24時間です
- 期限が来ると自動的に締め切られ、その時点で最高額を入札していた人が落札者になります

## 落札後の流れ

:::caution 注意
落札しても、土地の名義変更と代金の支払いは**自動化されていません**。落札するとメールで通知が届きますので、案内に従って運営とやり取りしてください。
:::

## 権限

| 権限 | 説明 | 既定 |
|---|---|---|
| オークションの閲覧・入札 | 一覧の閲覧、入札 | 全員 |
| オークションの作成・管理 | 新規オークションの作成 | OP |
