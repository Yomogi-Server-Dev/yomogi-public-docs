# ドア保護

複数人で同じ土地を共有している場合や、マンションの経営を行っている方に向けて、**土地保護とは別にドア・トラップドア・フェンスゲートを個別に施錠**できる機能です。

:::danger 他人のドアには触れないこと
保護されているドアなどに所有者以外(OPを除く)が触れると、以下が**同時に**発生します。

1. 「このドアは `<所有者>` によってロックされています。」と警告表示
2. **サーバーから強制キック**
3. いつ・誰が・誰のドアに触れたかが**ペナルティログに記録**

いたずらや誤操作でも容赦なくキックされるので、他人が保護したドアには触れないようにしてください。
:::

## 使い方

いずれのコマンドも、実行すると次にタップしたドア/トラップドア/フェンスゲートが対象になります。

```
/doorlock            → タップしたドアを施錠する
```

**2枚重ね(ダブルドア)** の場合は、上半分・下半分どちらをタップしても同じドアとして扱われます。

## コマンド一覧

| command | 説明 | 権限 | 備考 |
|---|---|---|---|
| `/doorlock` | 触ったドアを保護する | 全員 | 保護すると、あなただけが開けられるようになります |
| `/doorunlock` | 触ったドアの保護を解除する | 全員 | 解除できるのは自分が保護したドアのみです |
| `/doorlist` | 自分が所有するドア保護の一覧を表示する | 全員 | |
| `/doorlog` | ペナルティログ閲覧モードに切り替える | 全員 | 有効中にドアをタップすると、そのドアで記録されたペナルティ履歴を表示します |
| `/doordebug` | 自分のドアでも強制的にペナルティを発生させるデバッグモードに切り替える | 全員 | 動作確認用のモードです。有効中はキックされるので注意してください |

## 保護できるドア

チェスト保護と異なり、**土地の所有者・共有者でなくてもドアを保護できます**。ただし、既に他人が保護しているドアを保護することはできません。

:::tip
`fill`コマンド等でドアそのものを別のブロックに置き換えた場合、保護の記録が残っていても判定は行われなくなります。
:::

## 料金

ドア保護は、すべての機能が無料で利用できます。
