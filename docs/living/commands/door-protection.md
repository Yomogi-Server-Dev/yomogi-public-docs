# ドア保護

複数人で同じ土地を共有している場合や、マンションの経営を行っている方に向けて、土地保護とは別でドア・トラップドア・フェンスゲートを保護する機能があります。

:::caution 注意
保護されているドアなどに所有者以外(OPを除く)が触れると、警告メッセージとともに**サーバーからキックされ**、いつ・誰が・誰のドアに触れたかがペナルティログに記録されます。他人が保護したドアには触れないようにしてください。
:::

## コマンド

| command              | 説明                    | 権限 | 備考                                                           |
|----------------------|-----------------------| ---- |--------------------------------------------------------------|
| /doorlock               | 触ったドアを保護します         | 全員 | このコマンドで保護したドアは、あなただけが開けれるようになります                           |
| /doorunlock             | 触ったドアの保護を解除します      | 全員 | 解除できるのは自身が保護したドアのみです |
| /doorlist               | 所有しているドア保護の一覧を表示します    | 全員 | 
| /doorlog               | ペナルティログ閲覧モードに切り替えます    | 全員 |                                                              |
| /doordebug               | ぺナルティが強制付与されるデバッグモードに切り替えます    | 全員 |                                                              |


## 保護できるドア

チェスト保護と異なり、土地の所有者でなくてもドアを保護できます。ただし、他人がすでに保護しているドアを保護することはできません。

## 料金

ドア保護は、すべての機能が無料で利用できます。
