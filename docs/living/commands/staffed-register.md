# 有人レジ

有人レジを使うと、店員が商品をその場で登録して、お客さんが看板をタップするだけで支払えるレジを作れます。  
[チェストショップ](/docs/living/commands/chest-shop)と違って手数料がかからないのが利点ですが、設置に1,000YGかかります。

## 有人レジの作り方

1. 保護した土地の中に看板を設置します。このとき、文字が書き込まれる面がお客さんの立つ側を向くようにしてください(看板には何も書き込まないでください)
2. `/rgadd`を実行します
3. 設置した看板をタップ(PCでは右クリック)します

## 有人レジの使い方

店員が看板をタップすると、商品を追加できます。  
確定ボタンを押すとお客さん側に支払金額が表示され、そのあとお客さんが看板をタップすると支払いが完了します。  
有人レジでは、アイテムの受け渡しは自動では行われません(お客さんが何かを購入した場合、そのアイテムは店員が手渡しする必要があります)。

### 無人レジとして使う

看板をスニークしたままタップすると、レジの設定画面が開きます。ここで「固定支払い料金」を設定すると、店員が商品を登録しなくても、お客さんが看板をタップするだけで決まった金額を支払える無人レジになります。  
固定支払い料金を空欄に戻すと、もとの(店員が商品を登録する)有人レジに戻ります。

## 有人レジを作成できる場所

有人レジを作成できるのは、自分が購入した土地、または自分が土地共有者になっている土地の中だけです。

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/rgadd` | 有人レジを作成する | 全員 |

## 料金

設置するときに1,000YGが必要です(壊して置き直しても返金はありません)。  
販売手数料はかからないので、販売価格の全額が売上になります。
