# プロフィール

自分や他のプレイヤーの情報(ミッション進捗・図鑑コンプリート率・レベル・所属会社・称号・所持金など)を1つの画面にまとめて見られる機能です。

## 使い方

| command | 説明 |
|---|---|
| /profile | 自分のプロフィールを開く |
| /profile `<プレイヤー名>` | 指定したオンラインプレイヤーのプロフィールを開く(名前の一部を入力すれば候補から補完されます) |

閲覧できるのはオンラインのプレイヤーのみです。プロフィール画面からは、ミッション進捗・図鑑コンプリート状況・レベル状況・所属会社・オンラインプレイヤー一覧などへ移動できます。

## 自分の画面だけでできること

- フレンドの管理(申請・承認・解除)
- 自己紹介文の編集(最大120文字)
- 統計情報の公開範囲の設定(「公開」または「フレンド限定」)
- 拠点の登録(最大5件、名前つき)

## 他プレイヤーの画面でできること

- いいね(♡)を付ける
- フレンド申請・承認・キャンセル・解除

## 権限

| 権限 | 説明 | 既定 |
|---|---|---|
| /profileの実行 | — | 全員 |
