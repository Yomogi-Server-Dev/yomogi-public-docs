# プロフィール

自分や他のプレイヤーの情報(ミッション進捗・図鑑コンプリート率・レベル・所属会社・称号・所持金など)を1つの画面にまとめて見られる機能です。

## 使い方

| コマンド | 説明 | 権限 |
|---|---|---|
| `/profile` | 自分のプロフィールを開く | 全員 |
| `/profile <プレイヤー名>` | 指定したプレイヤーのプロフィールを開く(名前の一部だけでも大丈夫です) | 全員 |

他の人のプロフィールを見られるのは、その人が**オンラインのとき**だけです。プロフィール画面からは、ミッションの進み具合・図鑑のコンプリート状況・レベル・所属会社・称号・オンラインプレイヤー一覧などへ移動できます。表示される項目はサーバーで動いている機能によって変わり、対応する機能が無い項目は自動的に隠れます。

:::tip 名前は途中まででOK
`/profile <プレイヤー名>`は名前の先頭数文字を入力するだけでも探してくれます。当てはまる人が複数いる場合は、いちばん短い名前のプレイヤーが選ばれます。
:::

## 見られる情報

| 項目 | 内容 |
|---|---|
| ミッションの進み具合 | 達成済みミッションの数など |
| 図鑑のコンプリート状況 | ガチャ・釣りの図鑑のコンプリート率 |
| レベル | 採掘・農業・釣りのレベル |
| 現在の役職 | 鯖民/木こり/採掘者/農家/エンチャンターなど |
| 所属会社と社内の役職 | 社長/課長/社員 |
| 称号 | これまでに手に入れた称号 |
| 所持金・プレイ時間 | — |
| 拠点 | 自分で名前をつけて登録した土地(最大5件) |

## 自分の画面だけでできること

- **フレンドの管理**(申請・承認・解除)
- **自己紹介文の編集**(最大120文字。超えた分は切り捨てられます)
- **公開範囲の設定**(「公開」=誰でも見られる、または「フレンド限定」)
- **拠点の登録**(名前をつけて最大5件)

## 他プレイヤーの画面でできること

- **いいね(♡)** を付ける
- **フレンド申請・承認・キャンセル・解除**
