# プロフィール

自分や他のプレイヤーの情報(ミッション進捗・図鑑コンプリート率・レベル・所属会社・称号・所持金など)を1つの画面にまとめて見られる機能です。

## 使い方

| command | 説明 |
|---|---|
| `/profile` | 自分のプロフィールを開く |
| `/profile <プレイヤー名>` | 指定したオンラインプレイヤーのプロフィールを開く(名前の一部を入力すれば候補から補完されます) |

閲覧できるのは**オンラインのプレイヤーのみ**です。プロフィール画面からは、ミッション進捗・図鑑コンプリート状況・レベル状況・所属会社・称号・オンラインプレイヤー一覧などへ移動できます。表示される項目は連携している他機能の導入状況によって変わり、対応する機能が無い項目は自動的に表示されません。

:::tip 名前の補完
`/profile <プレイヤー名>`は前方一致で補完されるので、名前の先頭数文字を入力するだけでも構いません。候補が複数ある場合は、最も短い名前のプレイヤーが選ばれます。
:::

## 見られる情報

| 項目 | 内容 |
|---|---|
| ミッション進捗 | 達成済みミッションの数など |
| 図鑑コンプリート状況 | ガチャ・釣りの図鑑コンプリート率 |
| レベル | 採掘・農業・釣りの熟練度 |
| 現在のJOB(役職) | 鯖民/木こり/採掘者/農家/エンチャンターなど |
| 所属会社と役職 | 社長/課長/社員 |
| 称号 | これまでに獲得した称号 |
| 所持金・プレイ時間 | — |
| 拠点 | 自分で名前をつけて登録した土地(最大5件) |

## 自分の画面だけでできること

- **フレンドの管理**(申請・承認・解除)
- **自己紹介文の編集**(最大120文字、超過分は切り詰められます)
- **統計情報の公開範囲の設定**(「公開」= 誰でも閲覧可、または「フレンド限定」)
- **拠点の登録**(最大5件、名前つき)

## 他プレイヤーの画面でできること

- **いいね(♡)** を付ける
- **フレンド申請・承認・キャンセル・解除**

## 権限

| 権限 | 説明 | 既定 |
|---|---|---|
| `/profile`の実行 | 自分・他人のプロフィールを開く | 全員 |
