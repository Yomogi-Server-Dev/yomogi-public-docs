# 建築マーケット

[土地保護](/docs/living/commands/land-protection)した区画を、建っている建物ごと売り買いできる不動産マーケット(土地と建物の売買所)です。個人と会社のどちらの向きでも取引でき、購入するとその土地の所有権がまるごと買い手に移ります。

## 使い方

`/bmarket`でカタログを開きます。

- **出品する** — 自分が所有する土地の上に立って実行します。「個人として」か「(課長以上として所属する)会社として」を選び、名前・価格・カテゴリ・説明を入力すると、審査なしですぐに出品されます。出品と同時にサーバー全体へお知らせが流れます
- 各出品の詳細画面から、いいね・見学(道案内)・**プレビュー**・購入・出品の編集や取り消し(売り手のみ)ができます
- **並び順を変更** — 新着順/価格が安い順/価格が高い順
- **カテゴリで絞り込む**(カテゴリごとの出品数も表示されます)
- **会社ランキング** — 販売件数・平均評価のランキング
- **購入履歴・評価** — 自分が購入した物件を評価できます
- **取引履歴を見る** — 直近50件の取引を誰でも見られます(書き換えはできません)

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/bmarket` | カタログを開く | 全員 |
| `/bmarket sell` | 今立っている自分の土地を出品する | 全員 |
| `/bmarket mylistings` | 自分が出品しているものの一覧を表示する | 全員 |
| `/bmarket rate <取引ID> <1〜5> [コメント]` | 購入した物件を評価する | 全員 |
| `/bmarket ranking` | 会社ランキングをチャットに表示する | 全員 |

## プレビュー(現地へ行かずに物件を見る)

売り手が「プレビュー視点」を設定している出品は、詳細画面から**プレビューを見る**を選ぶと、その場所へ12秒だけテレポートして物件を確認できます。時間が来ると自動的に元の場所へ戻ります。

売り手は、詳細画面の「現在地でプレビュー視点を設定する」を選ぶと、今自分が立って見ている景色をそのままプレビューに設定できます。座標を数値で入力して細かく調整することもできるので、空を飛べなくても空中に視点を置けます。

## 購入するとどうなる？

代金は、個人で買った場合は所持金から、会社で買った場合はその会社の銀行から支払われます。土地の所有権はまるごと買い手に移り、それまでの土地共有者は外れます。  
売れると、元の所有者にチャットと[メール](/docs/living/commands/mail)の両方で通知が届きます(オフラインでもメールで受け取れます)。
