# 建築マーケット

土地保護された区画を、建っている建物ごと売買できる不動産マーケットです。個人⇔会社どちらの向きでも取引でき、購入するとその土地の所有権が丸ごと買い手に移ります。

## 使い方

/bmarketでカタログを開きます。

- **出品する** — 自分が所有する土地の上に立って実行します。「個人として」か「(課長以上として所属する)会社として」を選び、名前・価格・カテゴリ・説明を入力すると、承認待ちなしですぐに出品されます。出品と同時にサーバー全体へ告知されます
- 各出品の詳細画面から、いいね・見学(道案内)・購入・出品の編集や取消(売り手のみ)ができます
- **並び順を変更** — 新着順/価格が安い順/価格が高い順
- **カテゴリで絞り込む**
- **会社ランキング** — 販売件数・平均評価のランキング
- **購入履歴・評価** — 自分が購入した物件を評価できます
- **取引履歴を見る** — 直近50件の取引を誰でも閲覧できます(読み取り専用)

## コマンド

| command | 説明 | 権限 |
|---|---|---|
| /bmarket | カタログを開く | 全員 |
| /bmarket sell | 自分が所有する土地の上に立って出品する | 全員 |
| /bmarket mylistings | 自分が売り手の出品一覧を表示する | 全員 |
| /bmarket rate `<取引ID>` `<1-5>` `[コメント]` | 購入した物件を評価する | 全員 |
| /bmarket ranking | 会社ランキングをチャットに表示する | 全員 |

購入すると、代金は個人であれば所持金から、会社であればその会社の金庫から支払われます。売れると、元の所有者へ通知が届きます(メール導入時はオフラインでも届きます)。
