# チェストショップ

チェストショップを利用することで、簡易的な無人販売店を作ることができます。

## チェストショップとは？

チェストショップは、自分が保護した土地の中に設置できる簡易的な無人販売所です。  
チェストの前に看板を置いて作成し、お客さんがその看板をタップ(PCでは右クリック)すると、チェストの中にあるアイテムを買ってもらえます。  
2025年5月15日以降は、その場まで行かなくてもコマンドで買える「遠隔購入」もできるようになりました。

## チェストショップの作り方

1. 保護した土地の中にチェストを設置し、そのチェストの正面の側面に看板を設置します(看板には何も書き込まないでください)
2. 設置したチェストの中に、売りたいアイテムを入れます
3. `/csadd`を実行します
4. 設置したチェストについている看板をタップします
5. 出てくる画面で、売りたいアイテムのIDが入力されていることを確認します(入力されていない場合は、手順2からやり直してください)
6. 販売個数と販売価格を設定します
7. 「送信」を押します

## アイテムを遠隔で購入する

1. `/csedit`を実行します
2. 遠隔で買いたいチェストショップの看板をタップします
3. 表示されたメッセージの先頭にあるショップID(3〜5桁の数字)を控えます
4. `/csbuy <ショップID>`を実行します(`<ショップID>`には手順3で控えた数字を入れます)
5. 購入個数を選び、「送信」を押します

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/csadd` | チェストショップを作成する | 全員 |
| `/csedit` | チェストショップの売上を確認する、またはチェストショップを編集する | 全員 |
| `/csbuy <ショップID>` | チェストショップ内のアイテムを遠隔で購入する | 全員 |

## チェストショップを作成できる場所

チェストショップを作成できるのは、自分が購入した土地、または自分が土地共有者になっている土地の中だけです。

## 料金

チェストショップの設置は無料です。ただし、次の手数料がかかります。

| 項目 | 手数料 |
|---|---|
| その場での販売 | 売上の8%(販売者が負担) |
| 遠隔購入 | 購入者が本来の価格の170%を支払い、上乗せ分の70%が手数料になります |

## 詳細な仕様

チェストショップの詳細な仕様は、[チェストショップ(補足資料)](/docs/living/supplement/chest-shop)で確認できます。
