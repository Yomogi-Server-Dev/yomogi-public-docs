# 会社プラグイン

会社プラグインを使うと、誰でも本格的な会社経営を行えるようになります。  
会社は運営に申請すれば無料で設立できますが、設立の際には審査があります。

`/company search`を使えば、誰でも今ある会社を検索できます。

## 社内の役職

会社の中の役職は、**社長・課長・社員**の3つです。  
社長は1人だけで、課長と社員の人数に制限はありません。

## コマンド

コマンドの`<会社名>`は、自分が会社を掛け持ちしていない場合は省略できます。  
また、`search`などの2つめの語は、他と区別できる長さまで入力すれば十分です(例: `/company search`は`/company se`でも動きます)。

| コマンド | 説明 | 権限 | 備考 |
|---|---|---|---|
| `/company search` | 会社を検索する | 全員 | |
| `/company own` | 自分が所属している会社の一覧を表示する | 社員 | |
| `/company employees <会社名>` | 社員の一覧を表示する | 社長/課長/社員 | |
| `/company add <社員名> <会社名>` | 社員を追加する | 社長と課長 | |
| `/company promote <社員名> <会社名>` | 社員を課長に昇格させる | 社長と課長 | |
| `/company demote <社員名> <会社名>` | 課長を社員に降格させる | 社長のみ | |
| `/company fire <社員名> <会社名>` | 社員を解雇する | 社長と課長 | |
| `/company give <社員名> <会社名>` | 社長の座を譲る | 社長のみ | |
| `/company deposit <金額> <取引理由> <会社名>` | 会社の銀行にお金を預ける | 社長/課長/社員 | |
| `/company withdraw <金額> <取引理由> <会社名>` | 会社の銀行からお金を引き出す | 社長と課長 | |
| `/company deposit` / `/company withdraw`(引数なし) | 上の2つの操作をフォームで行う | 社長/課長/社員 | |
| `/company pay <1人あたりの金額> [理由]` | 全社員にまとめて給料を支払う | 社長のみ | 会社の残高が足りない場合は実行されません |
| `/company payone <社員名> <金額> [理由]` | 社員1人だけに給料を支払う | 社長のみ | |
| `/company journal <会社ID> [ページ] [取引者名] [取引ID]` | 帳簿(お金の出入りの記録)を見る | 社長と課長 | |

## 料金

会社プラグインは、すべての機能を無料で利用できます。  
ただし、会社の設立には審査があります。

## 会社申請

[よもぎ生活鯖 会社申請Discordフォーム](https://discord.com/channels/971584941076926474/1467060485236199484)から申請することで、会社を設立できます(Discordサーバーに参加している必要があります)。  
申請には審査があり、運営が手作業で対応しているため、少々お時間をいただきます。ご了承ください。

## 公認企業制度

社員や取引先を思いやるための「優良企業ガイドライン」を守っている企業は「公認企業」になることができ、運営からさまざまな支援を受けられます。  
詳しくは[公認企業制度のページ](https://docs.ymg24.org/docs/living/supplement/good-standing-company)をご覧ください。
