# 便利な機能

コマンドを覚えなくてもすぐ使える、生活を便利にする小さな機能をまとめて紹介します。

## 座る

`/sit`で、その場に座れます。座布団など「座れるブロック」は、**素手で**タップするだけでも座れます。
降りるときはスニークしてください(乗り物から降りるときと同じ操作です)。

:::info 座れない場合
既に何かに乗っている、地面に立っていない(クリエイティブでの飛行中など)、座席を出せない場所にいる、といった場合は座れません。
:::

## チェスト・樽の自動整理

**何も持っていない状態で、スニークしながらチェストまたは樽をタップ**すると、中身を自動で並べ替えて整理してくれます。  
同じアイテムをまとめてから、アイテムの種類順に隙間なく詰め直します。整理中はチェストは開きません。普通に開きたいときは、スニークせずにタップしてください。

## チャットでローマ字入力・簡易電卓

- ローマ字(半角英数字)だけでチャットすると、自動でひらがな・漢字混じりの文章に変換して発言し直してくれます。日本語入力が苦手な端末(Nintendo Switchなど)でも会話しやすくなります
- `=1+2`のように`=`から始めてチャットすると、計算結果が**近く(半径15m以内)にいるプレイヤーにだけ**表示されます

これらの機能は、下記の「個人設定」からオン・オフを切り替えられます。

## 個人設定

/settingで、以下のような個人設定を変更できます。

| 設定項目 | 内容 |
|---|---|
| BGMの音量 | 1〜100で調整 |
| ローマ字投稿を日本語に変換 | 上記の自動変換機能のオン・オフ |
| 計算式を有効にする | 上記の簡易電卓機能のオン・オフ |
| ミッションを動的に追跡する | ミッションの進捗をリアルタイムで追いやすくする |
| エレベーター降下時にスニーク解除 | エレベーターで降りた後、スニーク状態が残らないようにする |
| 適正役職以外での採掘時に勧告文表示 | 役職に合わないブロックを壊したときの案内表示のオン・オフ |
| 画面左上に座標を表示 | 現在地の座標を常に表示する |
| よもぎ端末をインベントリ形式のUIで開く | よもぎ端末のメニューを、ボタン一覧ではなくチェスト風の画面で開く |

:::tip 設定画面はゲームの設定からも開けます
`/setting`のほかに、マインクラフトの「設定」→「サーバー」の欄からも同じ設定画面を開けます。  
参加した直後に開くと中身が空になることがあります。その場合は一度閉じて、開き直してください。
:::

## 座標表示

上記の個人設定と連動して、画面左上に現在の座標が表示されます(既定でオン)。

## 本を複製できる形で書き上げる

「本と羽ペン」にそのまま署名すると、内容を書き直すことも複製することもできなくなってしまいます。そのため、このサーバーでは直接の署名を止めて`/publish`へ案内しています。

`/publish`を実行すると、**手元の下書き(本と羽ペン)はそのまま残したまま**、署名済みの本を発行できます。1回100YGで、一度に10冊まで発行できます。

| command | 説明 | 権限 |
|---|---|---|
| `/publish` | 下書きを残したまま、署名済みの本を発行する | 全員 |
| `/permitsign` | 注意を理解した上で、直接署名を一時的に許可する | 全員 |

## 取引NPC

生活ワールドには、村人と同じ取引画面でアイテム交換ができるNPCが設置されている場所があります。タップするだけで取引画面が開きます(NPCの設置自体は運営が行います)。

## チュートリアルをもう一度受ける

サーバーに初めて参加すると、自動でチュートリアルが開始されます。もう一度チュートリアルを受け直したい場合は/tutorialを実行してください(チュートリアルを完了済みの場合のみ実行できます)。

## コマンドが分からなくなったら

| command | 説明 | 権限 |
|---|---|---|
| `/guide`(別名 `/commands`、`/cmdguide`) | サーバーで使えるコマンドを、カテゴリごとに一覧で見られるガイドを開く | 全員 |
| `/notice` | 運営からのお知らせを読む(新着は強調表示されます) | 全員 |

土地保護まわりのコマンドだけを探したいときは`/guards`も便利です。
