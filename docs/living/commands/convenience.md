# 便利な機能

コマンドを覚えなくてもすぐ使える、生活を便利にする小さな機能をまとめて紹介します。

## 座る

`/sit`で、その場に座れます。座布団など「座れるブロック」は、**素手で**タップ(PCでは右クリック)するだけでも座れます。  
降りるときはスニークしてください(乗り物から降りるときと同じ操作です)。

:::info 座れない場合
すでに何かに乗っている、地面に立っていない(クリエイティブでの飛行中など)、座席を出せない場所にいる、といった場合は座れません。
:::

## チェスト・樽の自動整理

**何も持っていない状態で、スニークしながらチェストまたは樽をタップ**すると、中身を自動で並べ替えて整理してくれます。  
同じアイテムをまとめてから、アイテムの種類順にすき間なく詰め直します。整理中はチェストが開かないので、ふつうに開きたいときはスニークせずにタップしてください。

## チャットでローマ字入力・簡易電卓

- ローマ字(半角英数字)だけでチャットすると、自動でひらがな・漢字まじりの文章に変換して発言し直してくれます。日本語の入力がしにくい端末(Nintendo Switchなど)でも会話しやすくなります
- `=1+2`のように`=`から始めてチャットすると、計算結果が**近く(半径15ブロック以内)にいるプレイヤーにだけ**表示されます

どちらの機能も、下記の「個人設定」からオン・オフを切り替えられます。

## 個人設定

`/setting`で、以下のような個人設定を変更できます。

| 設定項目 | 内容 |
|---|---|
| BGMの音量 | 1〜100で調整 |
| ローマ字投稿を日本語に変換 | 上記の自動変換機能のオン・オフ |
| 計算式を有効にする | 上記の簡易電卓機能のオン・オフ |
| ミッションを動的に追跡する | [ミッション](https://docs.ymg24.org/docs/living/commands/mission)の進み具合を、より細かく表示する |
| エレベーター降下時にスニーク解除 | [エレベーター](https://docs.ymg24.org/docs/living/commands/elevator)で降りた後、スニーク状態が残らないようにする |
| 適正役職以外での採掘時に勧告文表示 | [役職](https://docs.ymg24.org/docs/living/commands/role)に合わないブロックを壊したときの案内表示のオン・オフ |
| 画面左上に座標を表示 | 現在地の座標をいつも表示する(既定でオン) |
| よもぎ端末をインベントリ形式のUIで開く | [よもぎ端末](https://docs.ymg24.org/docs/living/commands/custom-items)のメニューを、ボタン一覧ではなくチェスト風の画面で開く |

:::tip 設定画面はゲームの設定からも開けます
`/setting`のほかに、マインクラフトの「設定」→「サーバー」の欄からも同じ設定画面を開けます。  
参加した直後に開くと中身が空になることがあります。その場合は一度閉じて、開き直してください。
:::

## 本を書き直せる形で発行する

「本と羽ペン」にそのまま署名すると、内容を書き直すことも複製することもできなくなってしまいます。そのため、このサーバーでは直接の署名を止めて`/publish`を案内しています。

`/publish`を実行すると、**手元の下書き(本と羽ペン)を残したまま**、署名済みの本を発行できます。1回100YGで、一度に10冊まで発行できます。

| コマンド | 説明 | 権限 |
|---|---|---|
| `/publish` | 下書きを残したまま、署名済みの本を発行する | 全員 |
| `/permitsign` | 注意を理解した上で、直接署名を一時的に許可する | 全員 |

## 取引NPC

生活ワールドには、村人と同じ取引画面でアイテムを交換できるNPCが置かれている場所があります。タップするだけで取引画面が開きます(NPCを置けるのは運営だけです)。

## チュートリアルをもう一度受ける

サーバーに初めて参加すると、自動でチュートリアルが始まります。もう一度受け直したい場合は`/tutorial`を実行してください(チュートリアルを完了している場合のみ実行できます)。

## コマンドが分からなくなったら

| コマンド | 説明 | 権限 |
|---|---|---|
| `/guide`(別名 `/commands`、`/cmdguide`) | サーバーで使えるコマンドを、カテゴリごとに一覧で見られるガイドを開く | 全員 |
| `/notice` | 運営からのお知らせを読む(新着は目立つように表示されます) | 全員 |
| `/tutorial` | チュートリアルをもう一度受ける | 全員 |
| `/sit` | その場に座る | 全員 |
| `/setting` | 個人設定の画面を開く | 全員 |

[土地保護](https://docs.ymg24.org/docs/living/commands/land-protection)まわりのコマンドだけを探したいときは`/guards`も便利です。
