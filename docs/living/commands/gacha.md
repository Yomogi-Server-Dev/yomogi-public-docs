# ガチャ

ゲーム内でガチャを引いて、さまざまなアイテムを獲得できる機能です。

## ガチャの種類

| ガチャ | 消費 | 引ける時間帯 | 特徴 |
| --- | --- | --- | --- |
| 通常ガチャ | チケット1枚 | 常時 | — |
| 平日ランチタイムガチャ | チケット2枚 | 平日(月〜金)の午前11時〜午後3時 | 通常ガチャよりレアなアイテムが出やすくなっています |
| ダイヤモンドガチャ | ダイヤモンド2個 | 常時(1日50回まで) | 景品は通常ガチャと同じですが、レアなアイテムがかなり出やすくなっています |

このほか、期間限定ガチャも不定期で開催しています。

:::tip
ガチャを1回引くごとに、1%の確率でエンチャント本がおまけで付いてきます。  
とてもレアな景品(Mythic以上)を引き当てると、チャットでサーバー全体にお知らせが流れます。
:::

## ガチャの引き方

`/gacha`(別名`/gatya`)でガチャのフォームを開いて「ガチャを引く」を選択し、引きたいガチャを選びます。
何回ガチャを引くか(1〜250回)をフォームに入力して「送信」ボタンを押すと、まとめてガチャを引くことができます。

## 統計確認

サーバー全体の統計と個人の統計を確認できます。
統計画面ではガチャを引いた数と今まで排出されたアイテムの数と排出確率が表示されます。

![gacha-statistics](./img/gacha2.png)

## 図鑑

これまでに排出されたアイテムの図鑑をフォームから確認できます。集めた景品の種類が50%に達するとチケットと記念メダルがもらえます。100%(コンプリート)するとさらに豪華な報酬がもらえます。

記念メダルを手に持つと、数秒間パーティクルの演出が出ます。

## 使うと効果がある景品

ガチャの景品の中には、**持って右クリック(タップ)すると効果が出る**アイテムが約25種類あります。

| 種類 | 例 |
|---|---|
| お金がもらえる | 小切手、レッドワイン、ギフトカード、ビットコイン、大エメラルド |
| チケットがもらえる | 記念金貨、記念銀貨、管理システムコア |
| ワープ・移動 | テレポーター、偽造市民登録端末、違法転送ビーコン |
| その他 | ゴッドポーション、すごいリンゴ、隕石、ミステリーボックス など |

このほか、飾り用の**帽子**(70種類)も景品に含まれています。頭の防具スロットに入れると帽子として表示され、攻撃を受けても壊れません。

## コマンド

| command | 説明 | 権限 |
|---|---|---|
| `/gacha`(別名 `/gatya`) | ガチャのメインメニューを開く | 全員 |
| `/gacha draw` | ガチャの種類選択を直接開く | 全員 |
| `/gacha exchange` | チケット交換を直接開く | 全員 |
| `/gacha zukan` | 図鑑を直接開く | 全員 |
| `/gacha stats` | 自分の統計を直接開く | 全員 |
| `/gacha ranking` | ランキングを開く | 全員 |
