# 経験値で動くバフ防具

装着している間だけ経験値を少しずつ消費して効果を発揮する、特別な防具4種です。

## アイテム一覧

| アイテム | 部位 | 効果 |
|---|---|---|
| 俊足の経験靴 / 熟練の経験靴(ダイヤ版) | ブーツ | 移動速度が上がる |
| 採掘の経験兜 / 熟練の経験兜(ダイヤ版) | ヘルメット | 採掘速度が上がる(Haste) |

## 使い方

装着している間、数秒おきに経験値を少しずつ消費しながら効果がかかり続けます。**同じ防具を装着し続けるほど効果のレベルが上がっていきます。**

- 経験値が無くなると効果が止まります
- 脱ぐと、少しの間だけ効果が残ってから自然に切れます
- 脱いだ直後はクールタイムがあり、その間に装着し直してもレベルは上がりません(付け外しを繰り返してすぐレベルを上げることはできません)
- ログアウトすると、装着で維持していた効果は解除されます

:::tip
ダイヤ版は経験値の消費量が少なく、同じ経験値でより長く効果を維持できます。
:::
