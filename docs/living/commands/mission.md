# ミッション

「石を100個掘る」「魚を釣る」といった目標(ミッション)を達成すると、賞金・アイテム・称号がもらえる機能です。何をすればいいか分からないときの目標にもなります。

## 使い方

`/mission`でミッション一覧・進捗確認のフォームが開きます。よもぎ端末からも開けます。

進捗は、ふだん通り遊んでいるだけで自動的に進みます(採掘・農業・釣り・買い物など、ミッションの種類に応じてカウントされます)。達成するとトースト通知と効果音でお知らせされ、報酬が受け取れます。

| command | 説明 | 権限 |
|---|---|---|
| `/mission` | ミッションの一覧・進捗を確認する | 全員 |

## ミッションの種類

| 種類 | 内容 |
|---|---|
| 通常 | いつでも挑戦できる、ずっと残るミッション |
| チュートリアル | 初めて参加したときのチュートリアルに合わせて進むミッション |
| デイリー | 毎日入れ替わる、その日だけのミッション |
| 隠し | 一覧には出てこない、条件を満たすと達成になるミッション |
| 保証 | 条件を満たせば確実に達成できるミッション |

## ミッションを追跡する

一覧からミッションを選んで「追跡」すると、画面下部のアクションバーに進捗が常に表示されるようになります。今どれくらい進んだかを見ながら遊べます。

:::tip
`/setting`の「ミッションを動的に追跡する」をオンにすると、進捗がよりリアルタイムに反映されます。
:::

## アイテム納品ミッション

一部のミッションは、決められたアイテムを**納品**することで進みます。対象のミッションを開くと「納品する」ボタンが出るので、押すとチェストのような画面が開きます。

1. 画面の左端に、必要なアイテムと残りの個数が表示されます
2. 空いているマスに納品したいアイテムを入れます
3. 画面を閉じると、必要な数だけ自動で消費されて進捗に加算されます

対象外のアイテムや、必要数を超えて入れた分はそのまま返ってきます。

納品の対象になるのは、洞窟やダンジョンの宝箱・埋蔵金など、**探検して自分で手に入れたアイテム**です(アメジストの欠片、名札、鞍、馬鎧、エンチャントの本、海の心など)。

:::caution 納品できないアイテムがあります
名前や説明文が付いているアイテム(ガチャの景品など)と、公式ショップ(`/shop`)で購入したアイテムは納品できません。見た目が同じでも受け付けられないことがあるので、その場合は自分で探しに行ってみてください。
:::

## 投票でデイリーミッションを達成する

サーバーリストサイト[MinePortal](https://mineportal.jp/)でよもぎサーバーに投票したあと、鯖内で`/vote`を実行すると、デイリーミッションの「草木に水を(vote)」が達成になり報酬がもらえます。投票は1日1回できます。

| command | 説明 | 権限 |
|---|---|---|
| `/vote` | MinePortalでの投票を確認して報酬を受け取る | 全員 |
