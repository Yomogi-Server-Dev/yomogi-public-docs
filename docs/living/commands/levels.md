# レベル(採掘・農業・釣り)

採掘・農業・釣りの3系統で、それぞれ独立してレベルが上がっていく制度です。ブロックを壊す・作物を収穫する・魚を釣るたびに経験値が入り、レベルアップするとお金とボーナスアイテムがもらえます。

エンダーチェストなど、一部の機能は特定のレベルに達していないと使えません(各機能のページを参照してください)。

## 使い方

/levels `[プレイヤー名]`で、自分または指定したプレイヤーのレベル進捗を確認できます。経験値の獲得・レベルアップ時には、画面上部にボスバーで一時的に表示されます。

## 経験値の入り方

| 系統 | 入る条件 |
|---|---|
| 採掘 | ブロックを壊す(植物・装飾ブロックなど「採掘ではない」ブロックは対象外) |
| 農業 | 完全に育った作物の収穫、および作物由来のアイテムのクラフト |
| 釣り | 魚を釣り上げる |

レベルが上がるほど、次のレベルに必要な経験値は多くなっていきます。

:::tip レベルアップ報酬
レベルが上がると、お金に加えてアイテム(装備やブロックなど)がもらえることがあります。内容は到達したレベルによって変わります。
:::

サーバー内には、各系統のレベルランキングを表示するホログラムが設置されている場所もあります。

## コマンド

| command | 説明 | 権限 |
|---|---|---|
| `/levels [プレイヤー名]` | 自分、または指定したプレイヤーのレベル進捗を確認する(オフラインのプレイヤーも指定可能) | 全員 |
