# アスレチック

アスレチックワールドで、コースのタイム計測やランキングに挑戦できる機能です。

## メニューを開く

`/athletic`でアスレチックのメニューを開きます。難易度(初級・中級・上級・超級・特別)を選び、挑戦したいステージを選ぶとその場所へワープします。全15ステージがあり、自己ベストタイムも一緒に表示されます。

:::tip 見た目を切り替えられます
`/setting`の「アスレチックメニューの見た目」で、ボタン一覧のフォームと、チェストのようなインベントリ画面のどちらかを選べます。
:::

## タイム計測

コースによっては、決まったブロックを踏むとタイム計測が始まり、ゴールのブロックを踏むと計測が終わって記録されます。画面下に経過時間が表示されます。

- 計測中はテレポート・死亡・退出のいずれかがあると記録されずにリセットされます
- 計測を開始した状態で10分経っても終わらない場合は、自動的にリセットされます
- 飛行中(クリエイティブ飛行など)はタイム計測を開始できません
- 計測開始と同時に、持っていたポーション効果などは全て解除されます

### 計測中は持ち物が変わります

タイム計測が始まると、それまで持っていたアイテムはいったん預けられ、コースによっては代わりに専用の道具が渡されます。計測が終わる・リセットされるいずれの場合でも、元の持ち物へ自動で戻ります。

## ゴール看板・ランキング看板

- **ゴール地点の看板をタップ**すると、賞金(称号がある場合は称号も)を受け取れます
- **ランキング看板をタップ**すると、そのコースのベストタイムTOP10と、これまでに挑戦してクリアした人数を確認できます

## 注意事項

コースを飛ばせてしまうエンダーパール・コーラスフルーツは、アスレチックワールド内では使用できません。

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/athletic` | アスレチックのメニューを開く | 全員 |
