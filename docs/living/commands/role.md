# 役職制度

よもぎサーバーには、原木の収集や鉱石採掘など、特定の活動を支援する「役職制度」があります。  
全プレイヤーは、あらかじめ用意された役職のうちのどれか一つを選ぶことができます。選んだ役職に合ったブロックを壊すとYGがもらえるので、[お金](/docs/living/commands/money)を稼ぐ基本になります。

:::caution 最初に必ず役職を変えましょう
参加した直後の役職は「鯖民」で、このままではどのブロックを壊しても報酬がもらえません。下記の「役職変更」を読んで、早めに自分に合った役職へ変更してください。
:::

## 役職の種類

### 鯖民

初期役職です。特に効果はありません。

### 木こり

原木や木材を壊すと5YGがもらえるほか、低い確率でエンチャント本が手に入ります。

### 採掘者

石を壊すと2YG、鉱石を壊すと3〜20YGがもらえるほか、これらのブロックを壊したときに低い確率でエンチャント本が手に入ります。  
2026年現在、各鉱石を壊したときに得られるYGは以下の通りです。

| 鉱石 | YG |
|:---:|:---|
| 石炭鉱石 | 3YG |
| 鉄鉱石 | 5YG |
| 金鉱石 | 5YG |
| ラピスラズリ鉱石 | 7YG |
| レッドストーン鉱石 | 3YG |
| ダイヤモンド鉱石 | 20YG |

得られるYGの量は、壊したブロックの数で数えます。  
たとえば、ラピスラズリ鉱石は1つのブロックから複数のラピスラズリが落ちますが、落ちた数にかかわらず、1回壊して得られるのは7YGです。

### 農家

スイカとかぼちゃを壊すと3YGがもらえるほか、小麦・サトウキビ・スイカ・かぼちゃを壊したときに低い確率でエンチャント本が手に入ります。

### エンチャンター

[エンチャント本を使った合成](/docs/living/commands/enchant)ができるほか、すべての固形ブロックを壊したときに低い確率でエンチャント本が手に入ります。

## 役職変更

役職は、`/role`コマンド、または[よもぎ端末](/docs/living/commands/custom-items)の「役職変更」から変更できます。

:::caution 変更には費用がかかります
役職変更は無料ではありません。

| タイミング | 変更費用 |
|---|---|
| サーバー参加から3日以内 | 1,000YG |
| それ以降 | 1,000,000YG |

初めのうちにいろいろな役職を試してみたい場合は、**参加から3日以内**に決めておくのがおすすめです。
:::

## 合った役職でないとブロックを壊せないワールドがある

一部のワールド(採掘ワールド・農業ワールドなど)では、合った役職を選んでいないとそもそもブロックを壊せません。それ以外のワールドでは壊すこと自体はできますが、報酬がもらえないだけです。

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/role` | 役職の確認・変更を行うフォームを開く | 全員 |
