# 投票報酬

サーバーリストサイト「[MinePortal](https://mineportal.jp/)」で投票すると、デイリーミッションをクリアして報酬がもらえます。

## 使い方

1. MinePortalのサーバーページで投票する
2. ゲーム内で`/vote`を実行する

投票していればデイリーミッション「草木に水を(vote)」がクリアされ、報酬を受け取れます。まだ投票していない場合や、その日のミッションを既にクリアしている場合は、理由付きのメッセージが表示されます。

:::tip
投票は1日1回反映されます。報酬の内容は[ミッション](https://docs.ymg24.org/docs/living/commands/mission)のデイリーミッション一覧から確認できます。
:::

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/vote` | 投票を確認してミッションをクリアする | 全員 |
