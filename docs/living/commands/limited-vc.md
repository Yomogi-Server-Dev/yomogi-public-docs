# 近距離VC

よもぎサーバーには、「近距離VC」(VC=ボイスチャット、声での会話)と呼ばれる、マインクラフトのサーバー内で近くにいる人としゃべることができる機能があります。  
生活鯖の近距離VCには、 https://vc.ymg24.org/ で参加できます。

## MinecraftとDiscordの連携

近距離VCに参加するためには、MinecraftのアカウントとDiscordのアカウントを連携(ひもづけ)する必要があります。  
連携の方法については、[近距離VCに参加できません](/docs/living/faq/lvc-faults)のページをご覧ください。  
なお、マイクラ人狼イベントなどに参加された方で、すでに連携をお済ませの方は、ここで改めて連携する必要はありません。

## Discord認証

近距離VCのサイト https://vc.ymg24.org/ にアクセスすると、Discordの認証サイトに移動します。  
連携に使ったDiscordアカウントでログインして認証を行うと、近距離VCのサイトを利用できるようになります。

:::danger
ログインする前に、Discordの認証サイトのURLが`https://discord.com/`で始まっていることを必ず確認してください。  
移動先のURLがこれ以外で始まっている場合は、パスワードなどを決して入力せず、運営までご報告ください。
:::

## 近距離VCで通話可能な相手

近距離VCに参加すると、同じく近距離VCに参加している他のプレイヤーのうち、生活鯖内で近くにいる人としゃべることができるようになります。  
鯖内で相手との距離が変わると、聞こえる音量も自動で変わります。

## 近距離チャット(テキスト版)

声で話せない・話したくない場合のために、文字でも近くの人だけとやり取りができます。チャットの先頭を`.`または`。`にして発言すると、**一定の距離(既定では15ブロック)以内にいるプレイヤーにだけ**届く特別なチャットになります。

```
.こんにちは
```

- 通常のチャットと違い、離れているプレイヤーには一切表示されません
- 届いた相手には、発言者がどちらの方向・何m先にいるかも一緒に表示されます
- 発言後、実際に届いた相手の一覧が自分に表示されます

## Web/Discordとの連携

近距離VCのサイトやDiscordから送られたチャットは、生活サーバー内のチャットにも表示されます。逆に、サーバー内の通常チャットも近距離VCサイト側に表示されます。
