# カジノ

生活ワールドには、看板をタップ(PCでは右クリック)して遊べるスロットマシンが設置されています。

## 遊び方

- 待機中のスロット看板には、レート(倍率)と料金がいつも表示されています
- 看板をタップするとスロットが回り、絵柄の揃い方に応じてYGがもらえます
- 2つ揃った時点(リーチ)では、パーティクルの演出と「リーチ!」の表示が出ます
- 3つ揃う(ジャックポット)と、看板の周りにパーティクルと効果音が出て、まわりのプレイヤーにも分かります
- 看板を**スニークしたままタップ**すると、遊ばずに配当表だけを確認できます
- 2分間(120秒)操作しないと自動でリセットされます(リセットの15秒前に警告が表示されます)

## 配当表

| 絵柄 | 3つ揃い配当 | 揃わなかった場合の1つあたり配当 |
|---|---|---|
| 木のツルハシ | 600 | 0 |
| 木の剣 | 600 | 0 |
| 作業台 | 5000 | 300 |
| かまど | 3000 | 40 |
| ジャンプタップ | 1500 | 20 |
| リーダーボタン | 1500 | 20 |

実際にもらえる金額は、上の表の配当に、その看板に設定されているレート(倍率)を掛けた額になります。

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/casino` | 配当表・自分の成績(通算/本日)・プレイ履歴・稼ぎランキング・設置されているスロット一覧を確認する | 全員 |

:::caution 注意
新しいスロットの設置は運営のみが行えます。
:::
