# カジノ

生活ワールドには、看板をタップして遊べるスロットマシンが設置されています。

## 遊び方

- 待機中のスロット看板には、常にレート(倍率)と料金が表示されています
- 看板をタップするとスロットが回転し、絵柄の揃い方に応じてYGが配当されます
- 2つ揃った時点(リーチ)ではパーティクル演出と「リーチ!」の表示が出ます
- 3つ揃う(ジャックポット)と、看板の周囲にパーティクルと効果音が出て周りのプレイヤーにも分かります
- 看板を**スニークした状態でタップ**すると、遊ばずに配当表だけを確認できます
- 120秒(2分)間操作しないと自動でリセットされます(リセットの15秒前に警告が表示されます)

## 配当表

| 絵柄 | 3つ揃い配当 | 揃わなかった場合の1つあたり配当 |
|---|---|---|
| 木のツルハシ | 600 | 0 |
| 木の剣 | 600 | 0 |
| 作業台 | 5000 | 300 |
| かまど | 3000 | 40 |
| ジャンプタップ | 1500 | 20 |
| リーダーボタン | 1500 | 20 |

配当額は、その看板に設定されているレート(倍率)を掛けた金額になります。

## コマンド

| command | 説明 | 権限 |
|---|---|---|
| /casino | 配当表・自分の成績(通算/本日)・プレイ履歴・稼ぎランキング・設置されているスロット一覧を確認する | 全員 |

:::caution 注意
新しいスロットの設置は運営のみが行えます。
:::
