# 釣果の売却

[釣り](/docs/living/commands/fishing)で手に入れた魚などを、まとめて売却できる機能です。

## 使い方

`/sellfish`を実行すると、頭の上あたりに一時的な売却用チェストが出現します。売りたいアイテムをそこに入れてチェストを閉じると、売却が確定します。

<Image img={require('./img/sellfish_chest.png')} alt="頭上に出現する売却用チェストの画面" />

閉じると、何がいくつ・いくらで売れたかの内訳を確認する画面が表示されます。**この画面でキャンセルすると、入れたアイテムは全額分そのまま返却されます**(インベントリに入りきらない分は足元に落ちます)。

<Image img={require('./img/sellfish_confirm.png')} alt="売却アイテムの確認画面(内訳と売却額)" />

:::info 売却額の目安
魚のレアリティが高いほど売却額は大きく伸びます。サイズが大きいほど売却額も上がりますが、伸び方はレアリティほど極端ではありません。
:::

:::caution 使えない場所があります
再生成されるワールド・アスレチックワールド・PvPワールドでは、売却チェストを作成できません。
:::

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/sellfish` | 釣果などを売却する | 全員 |
