# エレベーター

重量感圧板を使って、ジャンプ・スニークだけで上下移動できるエレベーターを作成できる機能です。コマンドはなく、決められた通りにブロックを設置するだけで誰でも作成できます。

## 作り方

1. **鉄ブロック**または**ダイヤモンドブロック**を設置する
2. そのブロックの上に**重量感圧板**を置く
3. これを縦に複数階ぶん並べる(階と階の間は**3ブロック以上**離すこと)

<Image img={require('./img/yomogi_elevator.png')} alt="エレベーターの作り方を示した図" />

## 使い方

感圧板の上に立つと、画面下に「↑ジャンプで上へ　↓スニークで下へ」という操作ヒントが常に表示されます。

- 感圧板の上で**ジャンプ** → 真上にある次のエレベーター階へワープ
- 感圧板の上で**スニーク** → 真下にある次のエレベーター階へワープ

ワープの前後には音とパーティクルの演出が出ます。移動に成功すると「↑ 上の階へ移動しました(12ブロック上昇)」のようなメッセージが表示されます。移動できないときは、階が近すぎる・遠すぎる・頭上に障害物がある・すでに最上階または最下階である、といった理由が画面下に表示されます。

:::tip
`/setting`の「エレベーター降下時にスニーク解除」をオンにしておくと、降りた後にスニーク状態が残ってしまうことを防げます。
:::

## 等級

土台に使うブロックによって、階と階の間に許される最大距離が変わります。

| 等級 | 土台ブロック | 階間の最大距離 |
|---|---|---|
| 鉄 | 鉄ブロック | 8ブロック |
| ダイヤモンド | ダイヤモンドブロック | 50ブロック |

<Image img={require('./img/yomogi_elevator2.png')} alt="鉄とダイヤモンドの等級の違いを示した図" />

ダイヤモンドブロックを使うと、鉄ブロック(最大8ブロック)よりずっと離れた最大50ブロック先の階へ移動できます。高層マンションなど、階数の多い建物におすすめです。

## 料金

エレベーターの作成・利用は、すべて無料です(必要なのはブロックの用意だけです)。
