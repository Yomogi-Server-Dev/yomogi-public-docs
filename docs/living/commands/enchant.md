# エンチャント

このサーバーでは、バニラのエンチャント台の代わりに独自のエンチャントシステムを使用します。バニラの/enchantコマンドは、OP以外は使用できません。

## 使い方

エンチャント本をインベントリに持った状態で/anvilを実行すると、フォームが開き、手に持った道具や防具へエンチャントを合成できます。

:::caution 注意
合成には失敗する可能性があり、**失敗するとエンチャント本と対象のアイテムの両方を失います。** 失敗確率は、合成しようとしているエンチャントの最大レベルが高いほど上がります。
:::

エンチャントできるのは、個数1かつ未エンチャントの道具・防具のみです。

## コマンド

| command | 説明 | 権限 |
|---|---|---|
| /anvil | 手に持った道具・防具へエンチャントを合成する | 全員 |

役職(採掘者/木こり等)によっては、/anvilの実行に「エンチャンター」役職が必要になる場合があります。詳しくは[役職制度のページ](https://docs.ymg24.org/docs/living/commands/role)を参照してください。
