# エンチャント

このサーバーでは、バニラのエンチャント台の代わりに**独自のエンチャント本合成システム**を使用します。バニラの`/enchant`コマンドは、OP以外は使用できません。

## 使い方

エンチャント本をインベントリに持った状態で`/anvil`を実行すると、フォームが開き、手に持った道具や防具へエンチャントを合成できます。合成は**無料**です。

:::caution 失敗すると両方消えます
合成には失敗する可能性があり、**失敗するとエンチャント本と対象のアイテムの両方を失います。** 失敗確率は、合成しようとしているエンチャントの最大レベルが高いほど上がります。ハイリスクな合成をする前は、よく確認してから実行してください。
:::

- エンチャントできるのは、**個数1かつ未エンチャントの道具・防具のみ**です
- 稀に、1回の合成で複数のエンチャントが同時に付与されることがあります

## エンチャント本の入手方法

エンチャント本は、主に以下の方法で手に入ります。

- 該当する役職(木こり・採掘者・農家など)でブロックを壊したときの報酬
- ガチャのおまけ景品

## コマンド

| command | 説明 | 権限 |
|---|---|---|
| `/anvil` | 手に持った道具・防具へエンチャントを合成する | 全員 |

:::info 役職による制限
役職(採掘者/木こり等)によっては、`/anvil`の実行に「エンチャンター」役職が必要になる場合があります。詳しくは[役職制度のページ](https://docs.ymg24.org/docs/living/commands/role)を参照してください。
:::
