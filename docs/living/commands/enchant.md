# エンチャント

このサーバーでは、バニラ(ふつうのマインクラフト)のエンチャント台の代わりに、**独自のエンチャント本合成システム**を使います。バニラの`/enchant`コマンドは、運営(OP)以外は使用できません。

## 使い方

エンチャント本を持ちものに入れた状態で`/anvil`を実行するとフォームが開き、手に持った道具や防具へエンチャントを合成できます。合成は**無料**です。

:::caution 失敗すると両方消えます
合成は失敗することがあり、**失敗するとエンチャント本と対象のアイテムの両方が消えてしまいます。** 失敗する確率は、合成しようとしているエンチャントの最大レベルが高いほど上がります。大事なアイテムに合成する前は、よく確認してから実行してください。
:::

- エンチャントできるのは、**1個だけ持っていて、まだエンチャントが付いていない道具・防具**です
- まれに、1回の合成で複数のエンチャントが同時に付くことがあります

## エンチャント本の入手方法

エンチャント本は、主に次の方法で手に入ります。

- 合った[役職](/docs/living/commands/role)(木こり・採掘者・農家など)でブロックを壊したときの報酬
- [ガチャ](/docs/living/commands/gacha)のおまけ景品

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/anvil` | 手に持った道具・防具へエンチャントを合成する | 全員 |

:::info 役職による制限
`/anvil`の実行に「エンチャンター」の役職が必要になる場合があります。詳しくは[役職制度のページ](/docs/living/commands/role)をご覧ください。
:::
