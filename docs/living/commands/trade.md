# プレイヤー間取引

プレイヤー同士でアイテムやお金を安全に交換できる機能です。片方が用意したものだけを取り込んで持ち逃げされる心配はなく、**双方が「準備完了」にするまでは何も動きません**。

## 使い方

[1] 取引したい相手に対して、**スニーク(しゃがみ)しながら右クリック(タップ)**します  
[2] 相手に確認ダイアログが表示され、「応じる」を選ぶと取引が始まります  
[3] 開始と同時に双方に取引メニュー(いつでも/tradeで開き直せます)が表示されます

取引メニューでできること:

- **提示金額を設定する**
- **自分の提示アイテムを開く** — 頭上に一時的なチェストが出現するので、渡したいアイテムを入れて閉じます
- **準備完了にする / 解除する** — 双方が準備完了になった瞬間に取引が成立します
- **取引をキャンセルする**

アイテムや金額を変更すると、両者の準備完了状態は自動的に解除されます。

## コマンド

| command | 説明 | 権限 |
|---|---|---|
| /trade | 進行中の取引メニューを開く | 全員 |
| /trade cancel | 進行中の取引、または承諾待ちの申請をキャンセルする | 全員 |

## 自動的にキャンセルされる場合

- 相手がオフラインになったとき
- 双方の距離が10ブロックより離れたとき
- どちらかが/trade cancelを実行したとき

キャンセルされると、提示していたアイテムはすべて返却されます。
