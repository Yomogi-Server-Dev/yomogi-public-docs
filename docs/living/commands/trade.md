# プレイヤー間取引

プレイヤー同士でアイテムやお金を安全に交換できる機能です。片方だけが渡して持ち逃げされる心配はなく、**お互いが「準備完了」にするまでは何も動きません**。

## 使い方

1. 取引したい相手を、**スニーク(しゃがみ)しながらタップ(PCでは右クリック)**します
2. 相手に確認画面が表示され、「応じる」を選ぶと取引が始まります
3. 開始と同時に、両方に取引メニューが表示されます(いつでも`/trade`で開き直せます)

取引メニューでできること:

- **提示金額を設定する**
- **自分の提示アイテムを開く** — 頭上に一時的なチェストが出現するので、渡したいアイテムを入れて閉じます
- **準備完了にする / 解除する** — お互いが準備完了になった瞬間に取引が成立します
- **取引をキャンセルする**

アイテムや金額を変更すると、両方の準備完了は自動的に解除されます。

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/trade` | 進行中の取引メニューを開く | 全員 |
| `/trade cancel` | 進行中の取引、または返事待ちの申請をキャンセルする | 全員 |

## 自動的にキャンセルされる場合

- 相手がオフラインになったとき
- お互いの距離が10ブロックより離れたとき
- どちらかが`/trade cancel`を実行したとき

キャンセルされると、提示していたアイテムはすべて返却されます。
