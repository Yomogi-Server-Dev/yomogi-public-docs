# アイテム交換ガチャ

[ガチャ](https://docs.ymg24.org/docs/living/commands/gacha)(チケットを使うガチャ本体)とは別に、決まったアイテム(ガチャ券)をその場で別のアイテムに変えられる、簡易的な交換ガチャもあります。

## 使い方

ガチャ券を手に持って右クリック(空中でもブロックに対してでも可)すると、ガチャ券が1個消費され、抽選で決まった景品が手に入ります。

景品には、コモン・アンコモン・レア・エピック・レジェンダリーの5段階のレアリティがあり、レアリティが高いほど出現率は低くなります。
