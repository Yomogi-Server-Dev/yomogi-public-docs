# ワープ

登録されている地点(ワープ地点)へ一瞬で移動できる機能です。よもぎサーバーはワールドがいくつにも分かれているので、`/warp life`(生活ワールド)や`/warp lobby`(ロビー)のように、まずはこのコマンドで行き先を選びます。

## 使い方

```
/warp <地点名>
```

その地点へワープします。地点には別名(エイリアス)が設定されていることがあり、正式な地点名・別名のどちらを入力してもワープできます。  
地点名を付けずに`/warp`だけを実行すると、**自分がワープできる地点の一覧**が表示されます。

代表的な地点の例:

| 地点名 | 移動先 |
|---|---|
| `lobby` | ロビーワールド |
| `life` | 生活ワールド |

このほか、ワールドの移動には次のコマンドも使えます。

| コマンド | 説明 | 権限 |
|---|---|---|
| `/warps` | ワールドを選んで移動するメニューを開く | 全員 |
| `/athletic` | アスレチックワールドへ移動する | 全員 |
| `/pvp` | PvPワールドへ移動する | 全員 |
| `/players` | 今オンラインのプレイヤーと、その人がいるワールドを一覧表示する | 全員 |

:::info ワープできない場合
地点によっては、その地点専用の許可(タグ)を持っているプレイヤーしかワープできないものがあります。ワープできない場合は、その地点がまだ自分に開放されていない可能性があります。イベント会場など、期間限定で開放される地点もあります。
:::

## ワールドごとのルール

行き先のワールドによって、できること・できないことが変わります。

| ワールド | 主なルール |
|---|---|
| 生活ワールド | 土地を買って自由に建築できます |
| 天然資源 | 決められた範囲(セーフエリア)の外に出ると、警告のあとロビーへ強制的に戻されます |
| 人工資源 | 決められたブロックだけ設置・破壊できます。斧で原木の皮を剥ぐことはできません |
| 採掘・農業 | 壊した鉱石や作物は時間がたつと元に戻ります。合った役職を選んでいないとブロックを壊せません(→[役職制度](/docs/living/commands/role)) |
| アスレチック | エンダーパール・コーラスフルーツは使用できません(コースを飛ばせてしまうため) |
| PvP | プレイヤー同士で戦えます。ブロックは壊せません |
| ロビーなど公共ワールド | お腹が減りません |

:::caution PvPワールドの注意
- 毒・鈍化・負傷などの**攻撃用ポーションは、PvPワールドの中でしか使えません**
- **体が透けて見えるスキン**(体の3分の1以上が透明なスキン)ではPvPワールドに入れません。入ったあとに透明なスキンへ着替えた場合も、ロビーへ戻されます
:::

## 権限

| 権限 | 説明 | 既定 |
|---|---|---|
| 誰でもワープできる地点へのワープ | 一般公開されている地点への`/warp` | 全員 |
| 運営限定の地点へのワープ | 運営作業用など非公開の地点への`/warp` | OP |
