# ワープ

登録されている地点へ一瞬で移動できる機能です。この機能を通じて、これまでのページで紹介した`/warp life`や`/warp lobby`といったコマンドが使えます。

## 使い方

```
/warp <地点名>
```

その地点へワープします。地点には別名(エイリアス)が設定されている場合があり、本名・別名のどちらを入力してもワープできます。

代表的な地点の例:

| 地点名 | 移動先 |
|---|---|
| `lobby` | ロビーワールド |
| `life` | 生活ワールド |

:::info ワープできない場合
地点によっては、その地点専用の許可(タグ)を持っているプレイヤーしかワープできないものがあります。ワープできない場合は、その地点がまだ自分に開放されていない可能性があります。イベント会場など、期間限定で開放される地点もあります。
:::

## 権限

| 権限 | 説明 | 既定 |
|---|---|---|
| 誰でもワープできる地点へのワープ | 一般公開されている地点への`/warp` | 全員 |
| 運営限定の地点へのワープ | 運営作業用など非公開の地点への`/warp` | OP |
