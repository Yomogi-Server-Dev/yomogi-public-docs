# ミュート機能

いやな気持ちになる相手や、距離を置きたいプレイヤーがいる場合は、ミュート機能を使うことで、そのプレイヤーのチャットなどを表示しないようにできます。

生活サーバー内で`/mute`を実行するか、[よもぎ端末](/docs/living/commands/custom-items)から「ミュート」を選ぶと利用できます。

## ミュートの効果

あるプレイヤーをミュートすると、次のようになります。

- ミュートしたプレイヤーの全体チャットが表示されなくなります。ただし、自分のチャットは相手に届きます
- [近距離チャット](/docs/living/commands/limited-vc)はお互いに届かなくなります
- ミュートしたプレイヤーの入退出メッセージが表示されなくなります
- そのほか、ミュートしたプレイヤーに関する一部のシステムメッセージが表示されなくなります
- お互いに[`/pay`での送金](/docs/living/commands/money)ができなくなります
- お互いに[`/mail`でのメール送受信](/docs/living/commands/mail)ができなくなります
- お互いに[土地保護・土地共有](/docs/living/commands/land-protection)ができなくなります

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/mute` | ミュートの設定・解除を行うフォームを開く | 全員 |

## ミュートしたら相手にばれる？

ミュートしても、そのことがすぐに相手に通知されることはありません。

ただし、相手が送金やメール、土地保護、土地共有を使おうとすると専用のエラーメッセージが出て失敗するため、ミュートしていることが相手に伝わります。また、これらの機能を使わない場合でも、相手からの呼びかけに返事がないことでミュートを疑われることがあります。

## 他プレイヤーにミュートされてしまったら？

ミュートされてしまった場合は、自分自身の言動に問題がなかったかどうかを振り返り、さらに他のプレイヤーからも同様にミュートを受けることの無いよう改善に努めることが大切です。

インターネット上でのコミュニケーションは相手の顔が見えませんので、外見で差別を受けることはありません。運営として特定の言動を禁じるつもりはありませんが、一般論として以下のような言動をとっていないか確認してみてください。

- 他のプレイヤーのプライベートに過度に踏み入っている
- 日頃から強い口調で話している
- 一方的に自分の話を続ける
- 第三者を下げていたり、不謹慎であったり差別的であったりする発言を繰り返している
- 相手方が避けているのにもかかわらずしつこく話しかけている
- 相手の言動に対して揚げ足取りをしたり、大げさに反応したりしている
- 初対面の人に対してため口を使っている

自身がミュートされてしまった場合は、相手方の気持ちを尊重し、距離を置きましょう。ミュートを解除してもらうために他の媒体を使用して意思疎通を図ることは、相手が熟考の末ミュートボタンを押したことを鑑みれば、たいていの場合に無意味であるか、なおさら嫌われる原因になります。

また、運営にミュートの解除を依頼されても、原則として相手方への取次ぎは行いませんのでご了承ください。ただし、約束や契約を行ったにもかかわらず相手方が(その約束や契約から逃げるために)ミュートを使用したと考えられる場合は運営までご相談ください。運営内で判断を行った後、相手方に約束や契約を履行するよう注意する場合があります。

画面越しであっても相手方は人間です。相手方の気持ちを尊重し、相手方が不快に感じるような言動は避けていただきますようお願いします。

## ミュートに関する例外

:::caution
- すでに成立した約束から逃げるためにこの機能を使用することはおやめください。約束(契約)の債務不履行が疑われる場合、運営からご連絡することがあります。
- すべての運営をミュートすると運営からの連絡が届かなくなるため、利用規約5.5により不利益を受ける可能性があります。
:::

## Discordのミュート

本ページで紹介しているミュート機能は**生活サーバー内でのみ**有効です。

Discord上でも距離を置きたい場合は、ユーザーブロック機能を利用したりVCの個別ユーザー音量を0にしたりするなどでご対応ください。
