# 車(乗り物)

生活ワールドには、乗って運転できる車両(車・バイクなど)が用意されています。

## 乗り方・運転方法

車両に近づいてタップすると搭乗できます。搭乗中はWASD操作で運転でき、車種によっては助手席に他のプレイヤーを同乗させることもできます。  
降りるときは、乗り物に乗っているときと同じスニーク(降車ボタン)を使用してください。

## 車両の種類を確認する

/vehicles listを実行すると、現在サーバーに用意されている車両の種類一覧を確認できます。

## 自分の土地の車両を移動する

自分が所有している、または土地共有者となっている土地に置かれている車両は、スニークしながら右クリック(タップ)することでアイテム化できます。  
アイテム化した車両は、ブロックに向かって使うことで再びその場に設置できます。

:::caution 注意
アイテム化した車両は見た目が**トロッコのアイテム**になりますが、正しく車として機能しますのでご安心ください。
:::
