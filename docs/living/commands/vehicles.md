# 車(乗り物)

生活ワールドには、乗って運転できる車両(車・バイクなど)が用意されています。車はショップでYGを払って購入でき、自分の持ち物として鍵をかけたり、性能を強化したりできます。

## 車を手に入れる

`/vehicles2 shop`でショップを開き、YGを払って車を購入します。買った車はその場に出てきて、**購入した時点であなたの所有物**になります。

所有している車は`/vehicles2 mycars`で一覧・管理できます。どこに置いたか分からなくなったときは`/vehicles2 find`で距離と方角が分かります。

## 乗り方・運転方法

車両に近づいてタップすると搭乗できます。搭乗中はWASD操作で運転でき、車種によっては助手席に他のプレイヤーを同乗させることもできます。  
降りるときは、乗り物に乗っているときと同じスニーク(降車ボタン)を使用してください。

- **クラクション** — `/vehicles2 horn`
- **今の状態を見る** — `/vehicles2 status`(燃料・所有者・強化の段階が分かります)
- 小さな段差は、前に進むだけで自動で乗り越えます

## 燃料と給油

車は走ると**燃料**を消費します。燃料が切れると走れなくなるので、こまめに給油してください。

- 街なかに設置されている**給油スタンド**(`[給油]`と書かれた看板)をタップすると、近くにある自分の車を満タンまで給油できます。料金はYGで、燃料1単位あたりの価格は看板とホログラムに表示されています
- 所持金が足りない場合でも、**払える分だけ**給油されます
- 最寄りの給油スタンドは`/vehicles2 nearestgas`で探せます
- **燃料タンク**アイテムを持って、スニークせずに車を右クリックしても補充できます

:::caution 給油スタンドは運営が設置します
`[給油]`と書いただけの看板は給油スタンドにはなりません。設置できるのは運営だけです。
:::

## 車をしまう・置きなおす

車に**スニークしながら殴る(攻撃する)**とアイテム化して持ち運べます。アイテム化した車は、ブロックに向かって使うことで再びその場に設置できます。誰も乗っていない、ロックされていない車であればどこでもアイテム化できます。

:::caution 注意
アイテム化した車両は見た目が**トロッコのアイテム**になりますが、正しく車として機能しますのでご安心ください。
:::

:::danger 24時間放置すると自動で回収されます
**24時間以上だれも運転していない車は、自動的にアイテム化されて所有者へ返却されます。**(オフラインの場合は次にログインしたときに受け取れます。)道端に置きっぱなしにしないよう注意してください。
:::

## トランク(荷物入れ)

車に**スニークしながら右クリック(タップ)**すると、その車のトランクが開きます。アイテムを入れて運べます。  
トランクを開けられるのは所有者と信頼プレイヤーだけです。同乗している人にも開けさせたい場合は、`/vehicles2 trunkaccess`で切り替えてください。

## 鍵と、他の人との共有

自分の車を他の人に勝手に使われたくないときは、鍵をかけられます。

| やりたいこと | コマンド |
|---|---|
| 車をロックする / 解除する | `/vehicles2 lock` / `/vehicles2 unlock` |
| 特定の人に使わせる(信頼プレイヤー) | `/vehicles2 trust <名前>` |
| 信頼プレイヤーから外す | `/vehicles2 untrust <名前>` |
| 会社の同僚全員に使わせる | `/vehicles2 companyshare` |
| 車をあげる(所有権の譲渡) | `/vehicles2 transfer <名前>` |
| 名前をつける | `/vehicles2 rename <名前>` |

`/vehicles2 trust`は`,`で区切って何人かまとめて指定できます。所有権を譲渡すると、信頼プレイヤー・ロック・会社共有の設定はリセットされます。

会社で共有されている車(社用車)は`/vehicles2 companycars`で一覧できます。

## アップグレード(強化)

`/vehicles2 upgrade`でお金を払って車を強化できます。強化は車1台ごとで、段階には上限があります。

| 種類 | 効果 |
|---|---|
| エンジン(`engine`) | 最高速度が上がる |
| タンク(`tank`) | 燃料タンクの容量が増える |

強化にかかる費用は**元の車両価格と、次の段階の番号**によって決まります。高い車ほど、強化1段階あたりの費用も高くなります。効果や価格は車種ごとに異なります。

## 図鑑・ランキング

| command | 説明 |
|---|---|
| `/vehicles2 zukan` | 運転したことのある車種の図鑑を見る |
| `/vehicles2 stats` | 自分の総走行距離・所有台数・図鑑の進み具合を見る |
| `/vehicles2 top` | 走行距離ランキング(上位10人)を見る |
| `/vehicles2 gasstats` | 自分の給油回数・使った金額を見る |

図鑑はショップで買える車種が対象で、**50%で2,000YG、100%(コンプリート)で5,000YG**の報酬とサーバー全体へのお知らせがもらえます。

## コマンド一覧

`/vehicles2 help`でも一覧を確認できます。

| command | 説明 | 権限 |
|---|---|---|
| `/vehicles2 shop` | ショップで車を購入する | 全員 |
| `/vehicles2 mycars` | 所有している車の一覧・管理画面を開く | 全員 |
| `/vehicles2 status`(`/vehicles2 fuel`) | 運転中の車の状態を表示する | 全員 |
| `/vehicles2 find` | 自分の車までの距離・方角を表示する | 全員 |
| `/vehicles2 horn` | クラクションを鳴らす | 全員 |
| `/vehicles2 claim` | 誰の物でもない車を自分のものにする | 全員 |
| `/vehicles2 lock` / `/vehicles2 unlock` | 車をロック / 解除する | 所有者 |
| `/vehicles2 trust <名前>` / `/vehicles2 untrust <名前>` | 信頼プレイヤーを追加 / 削除する | 所有者 |
| `/vehicles2 transfer <名前>` | 所有権を譲渡する | 所有者 |
| `/vehicles2 rename <名前>` | 車にニックネームを付ける(32文字まで) | 所有者 |
| `/vehicles2 trunkaccess` | 同乗者がトランクを開けるかを切り替える | 所有者 |
| `/vehicles2 companyshare` | 会社の同僚を信頼済み扱いにするかを切り替える | 所有者 |
| `/vehicles2 upgrade [engine\|tank]` | 車をアップグレードする | 所有者 |
| `/vehicles2 nearestgas` | 最寄りの給油スタンドを案内する | 全員 |
| `/vehicles2 gasstats` | 自分の給油スタンド利用実績を表示する | 全員 |
| `/vehicles2 stats` | 走行距離・所有台数・図鑑進捗を表示する | 全員 |
| `/vehicles2 top` | 走行距離ランキングを表示する | 全員 |
| `/vehicles2 zukan` | 車種図鑑を表示する | 全員 |
| `/vehicles2 companycars` | 社用車の一覧を表示する | 全員 |

:::info 展示車両
`[展示車両]`と赤い文字で表示されている車は、運営が展示のために置いているものです。乗り降りはできますが走らせることはできず、持ち帰ることもできません。
:::

## その他

- 壁やモブにぶつかっても、車やプレイヤーがこわれたり傷ついたりすることはありません(耐久値の概念はありません)
- 車のアイテム化・設置に、土地保護の制限はかかりません。他人の土地の上にも置けてしまうので、迷惑にならないよう気をつけてください
