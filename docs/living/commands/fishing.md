# 釣り

このサーバーの釣りは、ふつうの統合版の釣りに「Fishing Power(釣り竿の性能)」「釣りレベル」「レアリティ(珍しさ)」「餌」「図鑑」といった要素を加えたものです。バニラ(ふつうのマインクラフト)には無い魚もたくさん釣れます。

## 釣り方

ふつうの統合版と同じく、釣り竿を使って釣ります。釣れる魚のレアリティは、**竿のFishing Power**・**[釣りレベル](/docs/living/commands/levels)**・**使っている餌**によって変わります。

## 餌(えさ)について

一定以上のFishing Powerを持つ竿を使っていると、腐った肉・クモの目・生の鶏肉・生の牛肉などを餌として使えます。餌の種類によってレアな魚が釣れる確率が変わり、**腐った肉 → クモの目 → 生の鶏肉 → 生の牛肉の順にレアな魚が出やすくなります**。

餌を持っていなくても釣りはできますが、レアな魚は餌ありのときより出にくくなります。

## 釣りメニュー

`/fishing`で釣りメニュー(図鑑・これまでの釣果一覧など)を開きます。図鑑は、集めた種類が50%・100%に達すると報酬がもらえます。

## 釣った魚を売る

`/sellfish`を実行すると、頭の上に売却用のチェストが一時的に出てきます。売りたい魚などをそのチェストに入れて閉じると、内訳(アイテム名×個数→売却額)を確認するフォームが表示され、「送信」で売却が確定します。

:::tip
確認フォームでキャンセルすれば、入れたアイテムはすべて返ってきます(持ちものに入りきらない分は足元に落ちます)。
:::

魚の売却額は、レアリティとサイズから自動で計算されます。レアリティが高い魚ほど売却額は大きく跳ね上がります。

:::caution 注意
復元されるワールド・アスレチックワールド・PvPワールドでは、売却用チェストを出せません。
:::

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/fishing` | 釣りメニュー(図鑑・釣果一覧)を開く | 全員 |
| `/sellfish` | 釣った魚などを売却する | 全員 |
