# 釣り

このサーバーの釣りは、通常の統合版の釣りに「Fishing Power(竿の性能)」「釣りレベル」「レアリティ」「餌」「図鑑」といった要素を追加したものです。バニラには無い魚もたくさん釣れます。

## 釣り方

通常の統合版と同じく、釣り竿を使って釣ります。釣れる魚のレアリティは、**竿のFishing Power**・**釣りレベル**・**使っている餌**によって変わります。

## 餌(えさ)について

一定以上のFishing Powerを持つ竿を使っている場合、腐った肉・クモの目・生の鶏肉・生の牛肉などを餌として使うことができます。餌の種類によってレア度の高い魚が釣れる確率が変わり、**腐った肉 → クモの目 → 生の鶏肉 → 生の牛肉の順にレアな魚が出やすくなります**。

餌を持っていなくても釣りはできますが、レアリティの出方は餌ありの場合より控えめになります。

## 使い方

/fishingで釣りメニュー(図鑑・これまでの釣果一覧など)を開きます。図鑑は集めた種類が50%・100%に達すると報酬がもらえます。

| command | 説明 | 権限 |
|---|---|---|
| /fishing | 釣りメニュー(図鑑・釣果一覧)を開く | 全員 |

## 釣った魚を売る

/sellfishを実行すると、頭上に一時的な売却用チェストが出現します。売りたい魚などをそのチェストに入れて閉じると、内訳(アイテム名×個数→売却額)を確認するフォームが表示され、売却が確定します。

:::tip
確認フォームでキャンセルすれば、入れたアイテムは全て返却されます(インベントリに入りきらない分は足元にドロップされます)。
:::

魚の売却額は、レアリティとサイズから自動計算されます。レアリティが高い魚ほど売却額は大きく跳ね上がります。

:::caution 注意
復元されるワールド・アスレチックワールド・PvPワールドでは、売却用チェストを作成できません。
:::

| command | 説明 | 権限 |
|---|---|---|
| /sellfish | 釣果などを売却する | 全員 |
