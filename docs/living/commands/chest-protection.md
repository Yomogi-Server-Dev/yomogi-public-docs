# チェスト保護

複数人で同じ土地を共有している場合や、マンションの経営を行っている方に向けて、**土地保護とは別にチェスト単位で保護**できる機能です。保護されたチェストは、権限を持たない人には**開けることも破壊することもできません**。

## 使い方

いずれのコマンドも、実行すると「次にタップしたチェストが対象」というタップ待ち状態になります。コマンドを実行したあと、対象のチェストをタップ(PCでは右クリック)してください。

1. `/clock`を実行する
2. 保護したいチェストをタップする
3. 以降、そのチェストはあなただけが開けられるようになります

**ダブルチェスト**(横に2つ並んだチェスト)の場合、片方だけタップすれば**ペアの片割れも一緒に保護**されます。

## コマンド一覧

| コマンド | 説明 | 権限 | 備考 |
|---|---|---|---|
| `/clock` | タップしたチェストを自分専用に保護する | 全員 | 保護したチェストは、あなただけが開けられるようになります |
| `/cpasslock <パスワード>` | タップしたチェストをパスワード付きで保護する | 全員 | パスワードを知っている人なら誰でも開けられます |
| `/cunlock` | タップしたチェストの保護を解除する | 全員 | 解除できるのは自分が保護したチェストだけです(パスワード保護の場合は、パスワードを知っていれば解除できます) |
| `/cinfo` | タップしたチェストの保護情報(所有者・作成日時・パスワード保護の有無)を確認する | 全員 | |

## パスワード保護について

`/cpasslock <パスワード>` で保護すると、**パスワードを知っている人なら誰でも**そのチェストを開けられるようになります。マンションの共用倉庫や、複数人で使うお店の在庫チェストなどに向いています。

- 保護後、初めてそのチェストを開けようとするとパスワード入力画面が表示されます
- 一度正しいパスワードを入力すると、**そのログインセッション中は入力不要**で開けるようになります

:::caution パスワードを忘れると開けなくなります
パスワードを紛失すると、**保護した本人であっても二度と開けられなくなります**。忘れないよう、必ず控えておいてください。
:::

## 保護できるチェスト

保護できるチェストは、**自分が購入した土地**、または**自分が土地共有者となっている土地**にあるものだけです。土地の外や他人の土地にあるチェストは保護できません。

また、ダブルチェストのペアが2つの土地にまたがっている場合は保護できません。

## 料金

チェスト保護は、すべての機能が無料で利用できます。
