# 役職の識別色

マイクラ人狼では、各役職に固有の文字色が割り当てられています。  

## 基本カラー

Minecraft標準の16色から使われているものです。

| 色 | 該当する役職 |
|---|---|
| 緑 | 市民、パン屋、狙撃手(市民陣営)、呪われし者、狼憑き |
| 青 | Blue、青鬼、占い師、透視者、預言者 |
| 黄 | 騎士 |
| 金 | 狂信者、リューク |
| 赤 | 人狼、一匹狼、サイコ |
| 灰色 | 憑依人狼 |
| ピンク | 霊媒師 |

## 拡張カラー(Bedrock版の特殊書式コード)

上記以外に、Bedrock版独自の拡張書式コード(`§h`〜`§u`など、鉱物の質感をイメージした色)も使われています。ソースコード上の名前とおおよその色味は次の通りです。

| ソースコード上の名前 | 色のイメージ | 該当する役職 |
|---|---|---|
| QUARTZ(クォーツ) | 白みがかったピンク | 無実の人 |
| FLORAL(アイアン系) | 明るい銀灰色 | エース、妖狐、偽善者(第三陣営)、てるてる |
| MARINE(ネザライト系) | 黒みがかった紫灰色 | 猫又 |
| SANGRIA(レッドストーン系) | 深い赤(ワインレッド) | 殺人鬼、化けの狼、感染者、殺し屋、改稿者、Red、封殺者、狙撃手(人狼陣営)、賢狼、繰替者、口封じ |
| GREEN_AQUA(カッパー系) | くすんだ橙(テラコッタ) | 権力者、偽善者(市民陣営) |
| DIRT(ゴールド系) | 黄金色 | 死神 |
| CANTALOUPE(エメラルド系) | 緑 | 青鬼(旧)、怪盗 |
| LEAF(ダイヤモンド系) | 青緑(ティール) | 独裁者、守護神、保安官、探偵 |
| ILLUSION(ラピス系) | 濃い青(ネイビー) | 技術者、知見者 |

:::tip
拡張カラーの正確な見え方は、お使いの端末やリソースパックの表示によって多少異なる場合があります。
:::
