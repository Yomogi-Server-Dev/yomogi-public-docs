# 便利なコマンド

マイクラ人狼で使えるコマンドのうち、アイテムの操作だけでは分かりにくい・アイテムと同じ内容をコマンドでも行える、といったものをまとめて紹介します。

## 統計・ランキング

| コマンド | 説明 |
|---|---|
| /stat | 自分の人狼の総試合回数・勝利回数・敗北回数を確認する |
| /rank | 自分の狙撃戦のスコア(キル数・デス数・キルレート)を確認する |
| /toprank | 狙撃戦のスコアランキングを確認する |

## 死亡後に役職一覧を確認する

`/c`(別名`/checkroles`)を実行すると、死亡後に全員の役職と生死状況の一覧を確認できます。生きている人は実行できません。

:::caution ゲーム中は口外しないでください
死亡後にこのコマンドで役職一覧を見られても、ゲームが終わるまでは他のプレイヤーに教えないようにしてください。
:::

## 会議中の操作をコマンドで行う

投票やCOは、[会議のページ](/docs/wolf/how-to-play/session)で説明しているとおりアイテム(金インゴット・レンガ)で行うのが基本ですが、同じ操作をコマンドで行うこともできます。

| コマンド | 説明 |
|---|---|
| /v `<投票先>`(別名`/vote`) | 指定した人に投票する(会議中のみ)。手には投票カード(金インゴット)を持っている必要があります。引数を省略するとフォームが開きます |
| /co(別名`/comingout`) | CO画面を開く(会議中のみ)。手にはCOカード(レンガ)を持っている必要があります |

## 役職の能力をコマンドで発動する

占い師・霊媒師・騎士など、役職カード(鉄インゴット)を持って地面をタップすることで発動する能力は、`/e <対象のプレイヤー名>`でも同じように発動できます。手には役職カード(鉄インゴット)を持っている必要があります。

## 主催者からの質問に回答する

主催者からアンケートのような質問が出されることがあります。その場合は`/a <回答番号>`(別名`/answer`)で回答できます。

## ロビー・観戦

| コマンド | 説明 |
|---|---|
| /lobby | ロビーへ移動する(ゲーム中は使用できません) |
| /stage | 観戦のためにステージへ移動する(ゲーム中は使用できません) |
