# 個人設定

マイクラ人狼のサーバー内で`/setting`コマンドを実行すると、以下のような個人設定を変更できます。

| 設定項目 | 内容 |
|---|---|
| BGMの音量 | 1〜100で調整します(変更が反映されるまで少し時間がかかることがあります) |
| デザインよりも読みやすさを重視した文字色にする | オンにすると、弱視の方やモニターに不良のある方でも文字を識別しやすい配色になります。詳しくは[アクセシビリティのページ](/docs/wolf/supplement/accessibility)を参照してください |
| ローマ字で投稿したチャットを日本語に変換する | チャット全体が半角英数字だけで構成されている場合、自動でひらがな・漢字混じりの文章に変換して発言し直します |
| ゲームに参加する | オフにすると、ゲーム中はスペクテイター(観戦者)として過ごします |
| ゲーム不参加時にステージにtpする | 「ゲームに参加する」をオフにしている場合、ゲーム開始時にステージへテレポートするかどうかを設定します |
| 画面の右上に今の役職の説明を表示する | オンにすると、常に自分の役職の概要が画面右上に表示され続けます |
| 試合結果を表示する | 試合終了時に結果を表示するかどうかを設定します |
| CO一覧にCOした役職名を表示する | 画面左下のCO一覧に、実際にCOされた役職名を表示するかどうかを設定します |
| 会議時間外でもCO一覧を表示する | オンにすると、会議中以外もCO一覧を表示し続けます |
| 外部ツールによる設定変更を許可する | 外部アプリケーションからあなたの設定を変更することを許可するかどうかを設定します |
| 役職が変更された際に通知する | 試合中に自分の役職が変わった場合に通知するかどうかを設定します |
| TTS互換のメッセージを表示する | 目が見えない方やモニターが故障している方向けの表示形式です。詳しくは[アクセシビリティのページ](/docs/wolf/supplement/accessibility)を参照してください |
| 人狼チャットの最初に付ける文字(プレフィックス) | 人狼陣営専用チャットの先頭に付ける記号を設定します(既定は`.`)。[定型文](/docs/wolf/supplement/fixed_text)の`{wc_prefix}`にも使われます |
| あなたのニックネーム/ニックネームの読み | Discord連携で使われる表示名と、その読み方(ひらがな)です |

:::tip 定型文の設定
発話できない方向けの定型文の設定は、`/setting`ではなく`/dict`から行います。詳しくは[定型文のページ](/docs/wolf/supplement/fixed_text)をご覧ください。
:::
