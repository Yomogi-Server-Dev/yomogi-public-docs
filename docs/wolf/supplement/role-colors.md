# 役職の識別色

マイクラ人狼では、各役職に固有の文字色が割り当てられています。

| 青 | Blue、青鬼、占い師、透視者、預言者 |
| 黄 | 騎士 |
| 金 | 狂信者、リューク |
| 赤 | 人狼、一匹狼、サイコ |
| 黒 | 憑依人狼 |

| 白 | 無実の人 |

| 空 | 猫又 |
| マゼンタ | 殺人鬼、化けの狼、感染者、殺し屋、改稿者、Red、封殺者、狙撃手(人狼陣営)、賢狼、繰替者、口封じ |
| 青緑 | 権力者、偽善者(市民陣営) |
