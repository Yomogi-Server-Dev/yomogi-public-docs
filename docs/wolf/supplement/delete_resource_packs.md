# リソースパックを削除する

リソースパックの削除の方法についてご案内します。CO一覧が画面いっぱいに表示される場合や、運営からの指示があった際にご利用ください。  

:::info ご案内
リソースパックが読み込まれない場合、単に**Minecraftを再起動する**だけで治る場合もあります。
:::

➀ Minecraftトップ画面の「設定」を押します

![手順1を示す画像](./img/delete_resource_packs_1.png)

② 左側側方の「ストレージ」を押します  
③ 「ダウンロードキャッシュをクリア」を押します  

![手順2と3を示す画像](./img/delete_resource_packs_2.png)

④ 「キャッシュされたデータ」の「管理」を押します

![手順4を示す画像](./img/delete_resource_packs_3.png)

⑤ 以下のテクスチャがあればすべて選択します。ない場合はスキップしてください  
「YOMOGI Wolf」「Yomogi Resource Pack」「YMGscr」「ChallengeComplete」「change music def」  
⑥ 「削除」を押します

![手順5と6を示す画像](./img/delete_resource_packs_4.png)

⑦ リソースパックは次回サーバーに参加した際に再ダウンロードされます
